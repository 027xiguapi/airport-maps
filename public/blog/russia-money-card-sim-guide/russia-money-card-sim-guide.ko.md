러시아에서 막 돌아와서, 가장 많이 궁금해하는 세 가지인 **환전, 은행 카드, 유심**에 대한 경험을 한 편으로 정리했습니다.

## 1. 환전

### 출국 전

1. **국내 은행에서는 루블을 거의 바꿀 수 없습니다** (적어도 선전에서는 바꿔 주는 은행이 없었습니다). 필자 두 사람은 **위안화 1800위안 + 미화 600달러** 현금을 챙겼지만 **부족했습니다**. 여기에 최소 1000위안은 더 준비하는 편이 좋습니다.
2. 다른 지역에서 국내 환율이 괜찮다면 **최소 1000루블**은 미리 바꿔 두세요. 공항에서 시내로 나가는 교통비로 쓸 돈입니다.

### 공항에서

공항 환전 창구는 **환율이 매우 나빠서 약 1 : 8.5**입니다. 그래서:

> **공항에서는 시내까지 갈 교통비 정도만 바꾸고**, 큰 금액은 시내에서 바꾸세요.

### 시내(정식 환전소)

- **붉은 광장의 GUM 백화점**: 3층에 정식 환전소가 있고, 당시 환율은 약 **1 : 11.5**였습니다.
- 환율이 더 좋은 곳은 시간이 없어 가 보지 못했으므로 여기서는 따로 추천하지 않습니다.

> 주의: 반드시 **정식 환전소**를 이용하고 개인 간 거래는 하지 마세요. 보호받지 못할 뿐 아니라 위조지폐나 분쟁이 생기기 쉽습니다.

## 2. 은행 카드: YooMoney(러시아 정식 은행 카드)

### 출국 전 등록

미리 **공식 홈페이지**에서 등록하면 되고, **자국 휴대폰 번호**로도 가능하며 절차는 금방 끝납니다.

### 입국 후 카드 수령과 활성화

1. **수령 장소**: 공항을 나와 **왼쪽으로 가면** **보라색 간판**이 보입니다. 아주 눈에 띕니다.
2. **발급**: 미리 자국에서 등록 정보를 입력해 두었다면 직원에게 보여 주기만 하면 바로 발급됩니다.
3. **활성화**: **3자리 코드는 앱 안에서 활성화**하며 아주 간단합니다. 직원이 알려 줍니다.
4. **충전**: 발급처 바로 옆에 충전기가 있고, **초록색 ✓ 표시가 있는 기기**를 고르세요(공항 밖도 마찬가지). 충전하면 **500루블 수수료가 자동으로 차감**됩니다.
5. **사용**: 활성화와 충전을 마치면 정상적으로 사용할 수 있습니다.

### 실제 사용에서 겪은 함정

- **휴대폰 번호로 하는 송금은 자주 실패합니다**: 여러 번 시도했지만 번호로 보낸 돈이 상대 계좌에 도착하지 않았습니다. **카드 번호로 직접 송금하는 편이 좋습니다**.
- **수수료를 주의하세요**: 공식 설명은 3%지만, 실제로는 **카드 번호로 100루블을 송금했을 때 148루블이 차감**되었습니다. 본격적으로 송금하기 전에 **2루블로 먼저 테스트**해 보세요.
- **지하철**: 두 사람이 따로 태그해도 문제없습니다.
- **버스**: 첫 번째 사람이 태그한 뒤 **카드를 다시 대고 옆면 버튼을 눌러** 인원을 추가하세요.

## 3. 유심과 데이터

필자 두 사람은 자국 온라인몰에서 산 **유심을 사용했고 로밍은 개통하지 않았습니다**. 실제 결과는 이렇습니다:

| 상황 | 신호 |
| --- | --- |
| 에르미타주 휴게 공간 | 신호 없음 |
| 무르만스크 공항 | 신호 없음 |
| 테리베르카 일부 도로 | 신호 없음 |
| 그 밖의 시간과 장소 | 정상 |

> 유심이 아예 신호를 잡지 못한 다른 여행자 사례도 보았습니다. 만일을 대비해 **현지 유심과 국제 로밍을 모두 준비**하세요. 하나는 데이터용, 하나는 예비용입니다.

## 정리

| 항목 | 권장 사항 |
| --- | --- |
| 현금 | 위안화와 달러를 함께 준비하면 한 가지 통화만 챙기는 것보다 유연합니다 |
| 공항 환전 | 교통비만 환전, 환율 약 1 : 8.5 |
| 시내 환전 | GUM 백화점 3층 등 정식 환전소, 약 1 : 11.5 |

| 송금 | 휴대폰 번호 대신 카드 번호, 소액으로 먼저 테스트 |
| 통신 | 현지 유심 + 로밍 이중 준비 |
