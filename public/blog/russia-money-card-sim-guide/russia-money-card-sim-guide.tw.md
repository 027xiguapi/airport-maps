剛從俄羅斯回來，把大家最關心的**換匯、銀行卡、電話卡**三件事整理成一份經驗帖。

## 一、換匯

### 出發前

1. **國內銀行基本換不到盧布**（至少在深圳沒有銀行可以換）。作者兩人帶了**人民幣 1800 元 + 600 美元**現金，實測**不夠用**，建議在此基礎上至少再加 1000 元人民幣。
2. 其他地區如果國內匯率合適，先換**至少 1000 盧布**，用於出機場的交通。

### 在機場

機場換匯視窗**匯率極差，約 1 : 8.5**。所以：

> **機場只換夠坐車到市區的錢**，大額留到市區再換。

### 在市區（正規換匯點）

- **紅場古姆百貨（GUM）**：三樓有正規換匯處，當時匯率約 **1 : 11.5**。
- 其他匯率更划算的地方作者沒來得及去，這裡不做推薦。

> 提醒：請務必走**正規換匯點**，不要私下私人交易——既不受保護，也容易遇到假鈔或糾紛。

## 二、銀行卡：YooMoney（俄羅斯正規銀行卡）

### 出發前註冊

提前在**官網**註冊，用**國內手機號**即可，流程很快。

### 落地後領卡與啟用

1. **領取點**：機場出門**往左走**，**紫色的門牌**就是，非常顯眼。
2. **髮卡**：已經把國內註冊資訊填好的，給工作人員看一眼就能直接髮卡。
3. **啟用**：**三位碼在 App 內啟用**，很簡單，工作人員會教你。
4. **充值**：辦理點旁邊就是充值機，**選擇帶綠色 ✓ 的機子**（機場外也一樣）。充值後會**自動扣 500 盧布手續費**。
5. **使用**：啟用並充值後即可正常使用。

### 使用中的幾個坑

- **手機號轉賬常失敗**：試過好幾次，通過手機號轉出的錢到不了對方賬戶，**最好直接用卡號轉**。
- **手續費要注意**：官方說法是 3%，但實測**通過卡號轉 100 盧布，實際被扣 148 盧布**。建議正式轉賬前先**轉 2 盧布測試**。
- **坐地鐵**：可以分開刷兩個人，沒有問題。
- **坐公交**：刷完第一個人後，**重新刷卡並按側面的按鈕**選擇加人。

## 三、電話卡與流量

作者兩人用的是國內電商買的**電話卡，未開通漫遊**。實測：

| 場景 | 訊號 |
| --- | --- |
| 冬宮休息區 | 無訊號 |
| 摩爾曼斯克機場 | 無訊號 |
| 捷裡別爾卡部分公路 | 無訊號 |
| 其他時間／地點 | 正常 |

> 也遇到過別人的電話卡完全無訊號的個例。保險起見，**建議「當地電話卡 + 國際漫遊」都準備**：一個走流量，一個備用。

## 小結

| 事項 | 建議 |
| --- | --- |
| 現金 | 帶人民幣＋美元雙幣種現金，比只帶一種更靈活 |
| 機場換匯 | 只換交通費，匯率約 1 : 8.5 |
| 市區換匯 | 古姆百貨三樓等正規點，約 1 : 11.5 |
| 銀行卡 | 提前官網註冊 YooMoney，機場紫色門牌領卡 |
| 轉賬 | 用卡號而非手機號，先小額測試 |
| 通訊 | 當地卡＋漫遊雙備 |
