仁川に深夜到着する場合、または未明のフライトで出発する場合、地下鉄は動いておらずタクシーは高くつきます。残るのは深夜バスとタクシーです。仁川空港のN系バスはソウル都心と両ターミナルを結び、運賃は2つの区分に分かれ、便数は少ないものの、どの便も決まった時刻に出発します。

本ガイドでは、5路線それぞれの役割、運賃、ソウルの出発場所、途中停車地、空港での降車場所を整理し、ソウル→空港の時刻表を下に掲載します。深夜便、夜通しの乗り継ぎ、地下鉄駅から遠いホテルは、いずれもその日の最後の移動という同じ問題に行き着きます。まず1点、この資料はソウル→空港方向を扱っています。空港→ソウルは空港公式の深夜バスページをご利用ください。

## 5路線の役割

深夜路線は5つあり、2つのグループに分かれます。N6000、N6001、N6002は江南、龍山、塩倉、松亭を通る安い運賃で、ソウル南西部を担当します。N6701とN6703は東大門とソウル駅から麻浦を通るか、蚕室からCOEXとソレマウルを通る高い運賃で、北東部と江南東側をカバーします。5路線とも市内から空港へ向かい、その時間帯は道路が空いており、時刻表では最初の停留所からT1までおおむね70〜90分です。

ターミナルは一律ではありません。N6000はT1のみ、N6001は主にT1で一部はT2のみ、N6002はT2のみ、N6701とN6703は両方を担当します。乗る前に自分がどちらのターミナルから飛ぶのか確認してください。T1とT2は鉄道で1駅離れており、夜間に移動するのは便利ではありません。荷物は下の荷物室に入れ、ドライバーが通常降りて手伝います。バスが路肩に着いてから荷物室を探すのではなく、数分早く着いてください。

![ソウルからT1への深夜バス路線図](./images/1.webp)

## 運賃：10,000ウォンか18,000ウォン

運賃は路線によって決まり、ちょうど倍の関係にある2つの区分があります。

| 路線 | 大人 | 子ども |
| --- | --- | --- |
| N6000、N6001、N6002 | 10,000ウォン | 8,000ウォン |
| N6701、N6703 | 18,000ウォン | 12,000ウォン |

松亭は例外で、そこから乗ると大人5,000ウォン、子ども4,000ウォンです。停留所が空港に近いためです。塩倉や松亭周辺に泊まるなら、松亭から乗るとそれなりの節約になります。

運賃は2026年10月公表のものです。変更は運行会社と空港に従います。乗り場の券売機、コンビニ、またはドライバーから購入してください。運用はさまざまで、その時間帯は窓口が閉まっているのが通常です。

## ソウルから空港へ：出発時刻

ソウルの出発は固定で、夜10時半過ぎに始まり、市内発の最終便は3:20ごろです。

| 路線 | ソウル出発場所 | 出発 | 到着 |
| --- | --- | --- | --- |
| N6000 | 江南高速バスターミナル | 22:30 / 23:20 / 00:10 / 01:10 / 02:00 / 02:50 | T1 23:40 / 00:30 / 01:20 / 02:20 / 03:10 / 04:00 |
| N6001 | ソウル駅 | 22:55 / 23:45 / 00:40 / 01:35 / 02:25 / 03:20 | T1 00:05 / 00:55 / 01:50 / 02:45 / 03:35 / 04:30 |
| N6002（1便） | 江南高速バスターミナル | 23:40 | T2 01:10 |
| N6002（2便） | ソウル駅 | 03:00 | T2 04:30 |
| N6701 | 東大門デザインプラザ（DDP） | 23:10 / 01:05 / 03:15 | T1 00:30 / 02:25 / 04:35、T2 00:50 / 02:45 / 04:55 |
| N6703 | 蚕室ロッテワールド | 23:20 / 01:15 / 03:20 | T1 00:35 / 02:30 / 04:35、T2 00:55 / 02:50 / 04:55 |

2つの点が重要です。同じバスがT1に先に停まり、約20分後にT2へ着くので、T2へ行くなら後の時刻を使ってください。N6701とN6703はそれぞれ夜に3便しかなく、1本逃すとほぼ2時間待つことになります。フライト前にぎりぎりの計画はやめてください。

また、時刻は最初の停留所の発車時刻で、途中停留所の時刻ではありません。途中から乗る場合は、停留所が路線のどこにあるかによって10〜25分を加えてください。迷ったら空港のサイトで停留所を調べてください。

## 途中停車地と空港の降車場所

ソウルの出発場所のほか、各路線はさらにいくつかの停留所に停まり、順序は路線ごとに異なります。

| 路線 | ソウル市内の停車地 | 空港の降車場所 |
| --- | --- | --- |
| N6000 | 江南高速バスターミナル→黒石→塩倉→松亭 | T1、1階、6A |
| N6001 | ソウル駅→新龍山→塩倉→松亭 | T1、1階、6A。一部便はT2 B1、24番ベイ |
| N6002（1便） | 江南高速バスターミナル→黒石→塩倉→松亭 | T2 B1、24番ベイ |
| N6002（2便） | ソウル駅→新龍山→塩倉→松亭 | T2 B1、24番ベイ |
| N6701 | DDP→乙支路1街→ソウル駅→麻浦 | T1、3階、3B。T2 B1、18番ベイ |
| N6703 | 蚕室ロッテワールド→COEX→ソレマウル | T1、3階、3B。T2 B1、19番ベイ |

降車場所はターミナルによって異なります。T1では6Aが1階到着ロビーの外、3Bが3階出発階の道路側です。T2ではB1交通センターが乗り換え拠点で、ベイ番号はドア番号です。降りたらターミナルの表示に従ってください。チェックインカウンターは出発階にあります。

T2ではB1交通センターを空港鉄道と共有しているため、バスのベイは列車の改札の隣にあります。T1では1階の路肩が到着ロビーのすぐ外にあり、道路を渡る必要はありません。

## 逆方向：空港からソウル

到着して市内へ向かうのは逆の旅で、路線も時刻も異なります。本ガイドはソウル→空港のみを扱います。空港→市内の深夜バスは空港ウェブサイトの「Transport & Parking → Public Transport → Bus → Late-night Bus (Terminal 1) → Seoul late-night bus」、[airport.kr/ap_ch/1702](https://www.airport.kr/ap_ch/1702/subview.do)をご利用ください。

このページはターミナル別に整理され、現行シーズンの路線、出発時刻、ベイ番号が載っており、二次情報の要約より確実です。まずT1とT2のどちらから出るかを決め、ベイ番号を照合してください。最終の深夜バスを逃した場合、空港鉄道の始発は5:15ごろなので、ターミナルで2〜3時間待てば市内へ行けます。それが長すぎるならタクシーです。

## 夜間の注意点

深夜バスは昼間よりはるかに少なく、ほとんどの路線が夜に3〜6便、N6002は2便だけです。逃すと1時間以上待つことがよくあります。最終便に近い時間に着陸するなら、機内にいるうちに入国審査と手荷物の時間を数えてください。逃せばタクシーしかありません。

タクシーは最後の手段です。仁川空港からソウル都心は距離制に夜間割増が加わり、バスより明らかに高いですが、ドア・トゥ・ドアで待ち時間がありません。荷物のある3〜4人のグループなら、1人あたりではタクシーのほうが安くなることがよくあります。

最後に2点。深夜路線の支払い方法はさまざまなので、乗る前に現金か交通系カードを用意してください。アナウンスは主に韓国語なので、降りる場所が不安なら名前を書き留めてドライバーに見せてください。フライトが未明まで遅延してバスが行ってしまった場合は、もう便がないかもしれない乗り場で待つ前に、ウェブサイトで後の便を確認してください。
