深夜落地仁川機場，或者趕凌晨的航班，地鐵已經停運，計程車又貴，能選的其實只剩深夜巴士和叫車。仁川機場的 N 字頭巴士連接首爾市區與兩座航廈，票價按線路分兩檔，班次不多，但每一班的發車時刻都是固定的。

這份指南整理五條線路的分工、票價、首爾發車站、中途停靠站和機場落客位置，並把首爾到機場方向的發車時刻抄成表格。紅眼航班、深夜轉機、住得離地鐵遠的旅客，都繞不開這一晚的交通安排。需要先說明：資料主要覆蓋「首爾→機場」方向；從機場回市區，請以仁川機場官網的深夜巴士頁面為準。

## 五條線路怎麼分工

深夜巴士一共五條，按走向可以分兩組。N6000、N6001、N6002 走江南、龍山、鹽倉、松亭一線，票價低，服務首爾西南部；N6701、N6703 走東大門、首爾站、麻浦與蠶室、COEX、瑞來村，票價高，覆蓋首爾東北部與江南東側。五條線都從市區往機場開，凌晨車流少，按表上的時刻算，從起點站到 T1 大約 70–90 分鐘。

落客航廈並不統一。N6000 只到 T1；N6001 多數班次到 T1，另有班次只到 T2；N6002 只到 T2；N6701 與 N6703 兩座航廈都到。上車前先確認自己落在哪個航廈，T1 與 T2 之間隔著一站鐵路，深夜轉場並不方便。行李放在車下的行李艙，司機通常會下來幫忙搬；箱子多就提前幾分鐘到站臺，別等車停穩了才找艙門。

![首爾到 T1 的深夜巴士線路圖與中途停靠站](./images/1.webp)

## 票價：10,000 韓元與 18,000 韓元兩檔

票價按線路分兩檔，差距剛好一倍。

| 線路 | 成人 | 兒童 |
| --- | --- | --- |
| N6000、N6001、N6002 | 10,000 韓元 | 8,000 韓元 |
| N6701、N6703 | 18,000 韓元 | 12,000 韓元 |

松亭站是一個例外：從這一站上車，成人 5,000 韓元、兒童 4,000 韓元，因為已經接近機場。住在鹽倉、松亭一帶，可以先到松亭站再上車，省下的錢不少。

價格是 2026 年 10 月的參考價，調整以現場和官網為準。買票可以用站臺的自動售票機、便利店，也可以上車後向司機購買，具體以現場為準；深夜時段售票視窗多半已經關閉。

## 從首爾出發：發車時刻

首爾到機場方向的班次是固定的，晚上十點半之後陸續發出，末班在 03:20 前後從市區開走。

| 線路 | 首爾發車點 | 發車時刻 | 抵達時刻 |
| --- | --- | --- | --- |
| N6000 | 江南高速巴士客運站 | 22:30 / 23:20 / 00:10 / 01:10 / 02:00 / 02:50 | T1 23:40 / 00:30 / 01:20 / 02:20 / 03:10 / 04:00 |
| N6001 | 首爾站 | 22:55 / 23:45 / 00:40 / 01:35 / 02:25 / 03:20 | T1 00:05 / 00:55 / 01:50 / 02:45 / 03:35 / 04:30 |
| N6002（1 車）| 江南高速巴士客運站 | 23:40 | T2 01:10 |
| N6002（2 車）| 首爾站 | 03:00 | T2 04:30 |
| N6701 | 東大門設計廣場（DDP）| 23:10 / 01:05 / 03:15 | T1 00:30 / 02:25 / 04:35；T2 00:50 / 02:45 / 04:55 |
| N6703 | 蠶室樂天世界 | 23:20 / 01:15 / 03:20 | T1 00:35 / 02:30 / 04:35；T2 00:55 / 02:50 / 04:55 |

表裡有兩個細節。同一班車先到 T1 再到 T2，兩站相差約 20 分鐘，去 T2 的話按後一個時刻安排。N6701、N6703 一晚只有三班，錯過一班要等近兩小時，趕飛機時別把時間壓得太緊。

還要注意，表上的發車時刻是從起點站開出的時間，不是經過中途站的時間。在中途站上車，要按起點站的時刻再加十幾到二十幾分鐘，站越遠越晚；拿不準就在官網按站點查。

## 中途站與機場落客位置

首爾的發車站之外，巴士沿途還會停幾站，具體位置和走向按線路不同。

| 線路 | 首爾沿途停靠 | 機場落客 |
| --- | --- | --- |
| N6000 | 江南高速巴士客運站 → 黑石站 → 鹽倉站 → 松亭站 | T1 1 層 6A |
| N6001 | 首爾站 → 新龍山站 → 鹽倉站 → 松亭站 | T1 1 層 6A；部分班次僅到 T2 B1 24 號 |
| N6002（1 車）| 江南高速巴士客運站 → 黑石站 → 鹽倉站 → 松亭站 | T2 B1 24 號 |
| N6002（2 車）| 首爾站 → 新龍山站 → 鹽倉站 → 松亭站 | T2 B1 24 號 |
| N6701 | 東大門設計廣場（DDP）→ 乙支路入口 → 首爾站 → 麻浦站 | T1 3 層 3B；T2 B1 18 號 |
| N6703 | 蠶室樂天世界 → COEX → 瑞來村 | T1 3 層 3B；T2 B1 19 號 |

落客位置按航廈分開。T1 的 6A 在 1 層到達層外側，3B 在 3 層出發層；T2 的地下一層是交通中心，出電梯就能看到站臺。下車後跟著航廈的指示牌走，辦登機牌的地方在出發層。

T2 的交通中心地下一層同時是機場鐵路和巴士的換乘層，站臺編號就是門牌號，按數字找過去即可。T1 的 1 層門外就是普通巴士與機場大巴的落客點，下車直接進到達廳，不用再穿行。

## 反向：從機場回市區怎麼查

機場落地後要進首爾，方向相反，線路和時刻不是同一套。這份資料只覆蓋首爾到機場，機場到市區的深夜巴士請查仁川機場官網：交通與停車 → 公共交通 → 巴士 → 深夜巴士（第 1 航廈）→ 首爾深夜巴士，頁面地址是 [airport.kr/ap_ch/1702](https://www.airport.kr/ap_ch/1702/subview.do)。

官網按航廈分列，能看到當季的線路、發車時刻和站臺號，比任何二手整理都準。落地後先看清自己從 T1 還是 T2 出來，再對頁面上的站臺位置。如果趕不上末班深夜巴士，機場鐵路的首班車在 05:15 前後，在機場等兩三個小時也能進城；不想等就叫車。

## 深夜乘車的幾點提醒

深夜巴士的班次密度遠低於白天，多數線路一晚只有三到六班，N6002 只有兩班，錯過一班往往要等一小時以上。落地時間接近末班，最好在飛機上就把入境和取行李的時間算進去；趕不上，就只剩計程車。

計程車是深夜的兜底方案。仁川機場到首爾市區按距離計價，夜間還有加成，費用明顯高於巴士，但門到門、不用等。幾個人同行、行李又多的話，叫車反而更划算。

還有兩點。深夜線路的支付方式以現場為準，上車前把現金或交通卡準備好；巴士在市區沿途停靠，報站以韓語為主，不確定在哪一站下，可以提前把站名寫給司機看。

還有一種情況：航班延誤到凌晨，原定那班巴士已經開走。先在官網核對還有沒有後續班次，沒有就按計程車的預算走，別在站臺上等一個不會來的班次。
