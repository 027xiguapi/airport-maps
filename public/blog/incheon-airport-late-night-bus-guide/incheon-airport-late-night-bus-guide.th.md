![ตารางรถบัสช่วงดึกจากโซลไปท่าอากาศยานอินชอน T1](./images/0.webp)

การลงจอดที่อินชอนตอนดึกหรือการออกเดินทางด้วยเที่ยวบินเช้ามืด รถไฟใต้ดินปิดให้บริการและแท็กซี่มีราคาแพง — จึงเหลือรถบัสช่วงดึกกับแท็กซี่ รถบัสสาย N ของท่าอากาศยานอินชอนเชื่อมใจกลางโซลกับอาคารผู้โดยสารทั้งสองหลัง ค่าโดยสารแบ่งเป็นสองช่วง และมีเที่ยวออกไม่มาก แต่ทุกเที่ยวออกตามเวลาที่กำหนด

คู่มือนี้อธิบายสิ่งที่แต่ละเส้นทางทั้งห้าทำ ค่าโดยสาร จุดออกเดินทางในโซล ป้ายจอดระหว่างทาง และจุดจอดส่งของแต่ละสายที่สนามบิน พร้อมตารางเวลาโซลไปสนามบินด้านล่าง เที่ยวบินกลางคืน การเปลี่ยนเครื่องข้ามคืน และโรงแรมที่อยู่ไกลจากสถานีรถไฟใต้ดิน ล้วนเจอคำถามเดียวกันเกี่ยวกับการเดินทางสุดท้ายของวัน อย่างแรกก่อน: เนื้อหานี้ครอบคลุมทิศทางโซลไปสนามบิน สำหรับสนามบินไปโซล ให้ใช้หน้าคู่มือรถบัสช่วงดึกของสนามบินเอง

## ห้าเส้นทางทำอะไร

มีห้าเส้นทางช่วงดึก แบ่งเป็นสองกลุ่ม N6000, N6001 และ N6002 วิ่งผ่านคังนัม ยงซาน ยอมชัง และซงจอง ด้วยค่าโดยสารที่ถูกกว่า ให้บริการทางตะวันตกเฉียงใต้ของโซล ส่วน N6701 และ N6703 วิ่งจากทงแดมุนและสถานีโซลผ่านมาโพ หรือจากจัมซิลผ่าน COEX และหมู่บ้านซอแร ด้วยค่าโดยสารที่สูงกว่า ครอบคลุมทางตะวันออกเฉียงเหนือและฝั่งตะวันออกของคังนัม ทั้งห้าเส้นทางวิ่งจากเมืองไปสนามบิน ถนนโล่งในเวลานั้น และตารางเวลาคิดออกมาประมาณ 70–90 นาทีจากป้ายแรกถึง T1

อาคารผู้โดยสารไม่เหมือนกันทุกสาย N6000 ให้บริการเฉพาะ T1; N6001 ส่วนใหญ่ให้บริการ T1 โดยบางเที่ยวไปเพียง T2; N6002 ให้บริการเฉพาะ T2; N6701 และ N6703 ให้บริการทั้งสองอาคาร ตรวจสอบว่าคุณบินจากอาคารไหนก่อนขึ้นรถ — T1 กับ T2 ห่างกันหนึ่งสถานีรถไฟ และการเปลี่ยนระหว่างกันตอนกลางคืนไม่สะดวก สัมภาระเก็บในช่องใต้ท้องรถ และคนขับมักลงมาช่วย มาถึงก่อนเวลาสองสามนาทีดีกว่าค้นหาช่องเก็บกระเป๋าเมื่อรถจอดที่ขอบทางแล้ว

![แผนที่เส้นทางรถบัสช่วงดึกจากโซลไป T1](./images/1.webp)

## ค่าโดยสาร: 10,000 วอนหรือ 18,000 วอน

ค่าโดยสารขึ้นอยู่กับเส้นทาง แบ่งเป็นสองช่วงที่ต่างกันหนึ่งเท่าพอดี

| เส้นทาง | ผู้ใหญ่ | เด็ก |
| --- | --- | --- |
| N6000, N6001, N6002 | 10,000 วอน | 8,000 วอน |
| N6701, N6703 | 18,000 วอน | 12,000 วอน |

ซงจองเป็นข้อยกเว้น: การขึ้นรถที่นั่นราคา 5,000 วอนสำหรับผู้ใหญ่และ 4,000 วอนสำหรับเด็ก เพราะป้ายอยู่เกือบถึงสนามบินแล้ว หากคุณพักแถวยอมชังหรือซงจอง การขึ้นที่ซงจองช่วยประหยัดได้พอสมควร

ค่าโดยสารเป็นไปตามประกาศเดือนตุลาคม 2026 การเปลี่ยนแปลงเป็นไปตามผู้ให้บริการและสนามบิน ซื้อได้ที่เครื่องจำหน่ายที่ชานชาลา ร้านสะดวกซื้อ หรือจากคนขับ — วิธีปฏิบัติแตกต่างกัน และหน้าต่างจำหน่ายตั๋วมักปิดในเวลานั้น

## โซลไปสนามบิน: เวลาออกเดินทาง

เที่ยวออกจากโซลเป็นเวลาคงที่ เริ่มหลังสี่ทุ่มครึ่งและสิ้นสุดด้วยรถเที่ยวสุดท้ายออกจากเมืองประมาณ 03:20

| เส้นทาง | จุดออกเดินทางในโซล | ออกเดินทาง | ถึง |
| --- | --- | --- | --- |
| N6000 | สถานีขนส่งทางไกลคังนัม | 22:30 / 23:20 / 00:10 / 01:10 / 02:00 / 02:50 | T1 23:40 / 00:30 / 01:20 / 02:20 / 03:10 / 04:00 |
| N6001 | สถานีโซล | 22:55 / 23:45 / 00:40 / 01:35 / 02:25 / 03:20 | T1 00:05 / 00:55 / 01:50 / 02:45 / 03:35 / 04:30 |
| N6002 (รถ 1) | สถานีขนส่งทางไกลคังนัม | 23:40 | T2 01:10 |
| N6002 (รถ 2) | สถานีโซล | 03:00 | T2 04:30 |
| N6701 | ทงแดมุนดีไซน์พลาซา (DDP) | 23:10 / 01:05 / 03:15 | T1 00:30 / 02:25 / 04:35; T2 00:50 / 02:45 / 04:55 |
| N6703 | จัมซิลล็อตเวิลด์ | 23:20 / 01:15 / 03:20 | T1 00:35 / 02:30 / 04:35; T2 00:55 / 02:50 / 04:55 |

มีสองรายละเอียดที่สำคัญ รถคันเดียวกันจอดที่ T1 ก่อน T2 ห่างกันประมาณ 20 นาที ดังนั้นหากจะไป T2 ให้ใช้เวลาที่หลัง N6701 และ N6703 วิ่งเพียงคืนละสามเที่ยว และการพลาดหนึ่งเที่ยวหมายถึงรอเกือบสองชั่วโมง — อย่าทำเวลาเฉียดเกินไปก่อนเที่ยวบิน

โปรดทราบด้วยว่าเวลาเหล่านั้นเป็นเวลาออกจากป้ายแรก ไม่ใช่จากป้ายระหว่างทาง หากขึ้นรถระหว่างทาง ให้บวกสิบถึงยี่สิบห้านาทีขึ้นอยู่กับว่าป้ายอยู่ไกลแค่ไหนตามเส้นทาง หากไม่แน่ใจ ให้ค้นหาป้ายนั้นบนเว็บไซต์สนามบิน

![ตารางรถบัสช่วงดึกจากโซลไป T1 และ T2](./images/2.webp)

## ป้ายจอดระหว่างทางและจุดจอดส่งที่สนามบิน

นอกจากจุดออกเดินทางในโซล แต่ละเส้นทางจอดเพิ่มอีกไม่กี่ป้าย โดยลำดับต่างกันในแต่ละสาย

| เส้นทาง | ป้ายในโซล | จุดจอดส่งที่สนามบิน |
| --- | --- | --- |
| N6000 | สถานีขนส่งทางไกลคังนัม → ฮึกซอก → ยอมชัง → ซงจอง | T1 ชั้น 1 6A |
| N6001 | สถานีโซล → ชินยงซาน → ยอมชัง → ซงจอง | T1 ชั้น 1 6A; บางเที่ยว T2 B1 ช่อง 24 |
| N6002 (รถ 1) | สถานีขนส่งทางไกลคังนัม → ฮึกซอก → ยอมชัง → ซงจอง | T2 B1 ช่อง 24 |
| N6002 (รถ 2) | สถานีโซล → ชินยงซาน → ยอมชัง → ซงจอง | T2 B1 ช่อง 24 |
| N6701 | DDP → อึลจีโร 1-กา → สถานีโซล → มาโพ | T1 ชั้น 3 3B; T2 B1 ช่อง 18 |
| N6703 | จัมซิลล็อตเวิลด์ → COEX → หมู่บ้านซอแร | T1 ชั้น 3 3B; T2 B1 ช่อง 19 |

จุดจอดส่งขึ้นอยู่กับอาคารผู้โดยสาร ที่ T1 ป้าย 6A อยู่นอกโถงขาเข้าชั้น 1 และ 3B อยู่บนถนนขาออกชั้น 3 ที่ T2 ศูนย์ขนส่งชั้น B1 เป็นจุดเปลี่ยนรถ และหมายเลขช่องคือหมายเลขประตู ทำตามป้ายอาคารผู้โดยสารหลังลงรถ เคาน์เตอร์เช็คอินอยู่บนชั้นขาออก

ที่ T2 ศูนย์ขนส่งชั้น B1 ใช้ร่วมกับรถไฟสนามบิน ช่องจอดรถบัสจึงอยู่ข้างประตูรถไฟ ที่ T1 ขอบถนนชั้น 1 อยู่นอกขาเข้าเลย ไม่ต้องข้ามถนน

![แผนที่เส้นทางรถบัสช่วงดึกจากโซลไป T1 และ T2](./images/3.webp)

## ทิศทางตรงกันข้าม: สนามบินไปโซล

การมาถึงและมุ่งเข้าเมืองเป็นการเดินทางย้อนกลับ ซึ่งมีเส้นทางและเวลาแตกต่างกัน คู่มือนี้ครอบคลุมเฉพาะโซลไปสนามบิน สำหรับรถบัสช่วงดึกจากสนามบินเข้าเมือง ให้ใช้เว็บไซต์สนามบิน: Transport & Parking → Public Transport → Bus → Late-night Bus (Terminal 1) → Seoul late-night bus ที่ [airport.kr/ap_ch/1702](https://www.airport.kr/ap_ch/1702/subview.do)

หน้านั้นจัดแบ่งตามอาคารผู้โดยสารและมีเส้นทาง เวลาออกเดินทาง และหมายเลขช่องของฤดูกาลปัจจุบัน ซึ่งดีกว่าบทสรุปมือสองใด ๆ กำหนดก่อนว่าคุณออกจาก T1 หรือ T2 แล้วจับคู่หมายเลขช่อง หากคุณพลาดรถบัสช่วงดึกเที่ยวสุดท้าย รถไฟสนามบินเที่ยวแรกออกประมาณ 05:15 ดังนั้นการรอสองหรือสามชั่วโมงในอาคารผู้โดยสารก็ยังพาคุณเข้าเมืองได้ หากนานเกินไป ให้เรียกแท็กซี่

## เรื่องที่ควรรู้ตอนกลางคืน

รถบัสช่วงดึกวิ่งน้อยกว่าบริการกลางวันมาก: เส้นทางส่วนใหญ่วิ่งคืนละสามถึงหกเที่ยว N6002 เพียงสองเที่ยว และการพลาดรถมักหมายถึงรอหนึ่งชั่วโมงหรือมากกว่า หากคุณลงจอดใกล้เวลาเที่ยวสุดท้าย ให้คำนวณเวลาตรวจคนเข้าเมืองและรับกระเป๋าขณะยังอยู่บนเครื่อง หากพลาด แท็กซี่เป็นทางเลือกเดียว

แท็กซี่เป็นทางสำรอง จากท่าอากาศยานอินชอนถึงใจกลางโซลคิดตามระยะทางพร้อมค่าบริการกลางคืน แพงกว่ารถบัสชัดเจน แต่ไปถึงหน้าประตูโดยไม่ต้องรอ สำหรับกลุ่มสามหรือสี่คนพร้อมสัมภาระ แท็กซี่มักถูกกว่าต่อคน

สองจุดสุดท้าย การชำระเงินบนเส้นทางกลางคืนแตกต่างกัน จึงควรเตรียมเงินสดหรือบัตรขนส่งก่อนขึ้นรถ การประกาศส่วนใหญ่เป็นภาษาเกาหลี หากคุณไม่แน่ใจป้ายของคุณ ให้เขียนชื่อป้ายและแสดงให้คนขับดู และหากเที่ยวบินล่าช้าถึงเช้ามืดและรถบัสของคุณออกไปแล้ว ให้ตรวจสอบเว็บไซต์ว่ามีเที่ยวหลังจากนั้นก่อนจะตั้งหลักรอที่ป้ายซึ่งอาจไม่มีเที่ยวออกอีก
