深夜落地仁川机场，或者赶凌晨的航班，地铁已经停运，出租车又贵，能选的其实只剩深夜巴士和打车。仁川机场的 N 字头巴士连接首尔市区与两座航站楼，票价按线路分两档，班次不多，但每一班的发车时刻都是固定的。

这份指南整理五条线路的分工、票价、首尔发车站、中途停靠站和机场落客位置，并把首尔到机场方向的发车时刻抄成表格。红眼航班、深夜转机、住得离地铁远的旅客，都绕不开这一晚的交通安排。需要先说明：资料主要覆盖「首尔→机场」方向；从机场回市区，请以仁川机场官网的深夜巴士页面为准。

## 五条线路怎么分工

深夜巴士一共五条，按走向可以分两组。N6000、N6001、N6002 走江南、龙山、盐仓、松亭一线，票价低，服务首尔西南部；N6701、N6703 走东大门、首尔站、麻浦与蚕室、COEX、瑞来村，票价高，覆盖首尔东北部与江南东侧。五条线都从市区往机场开，凌晨车流少，按表上的时刻算，从起点站到 T1 大约 70–90 分钟。

落客航站楼并不统一。N6000 只到 T1；N6001 多数班次到 T1，另有班次只到 T2；N6002 只到 T2；N6701 与 N6703 两座航站楼都到。上车前先确认自己落在哪个航站楼，T1 与 T2 之间隔着一站铁路，深夜转场并不方便。行李放在车下的行李舱，司机通常会下来帮忙搬；箱子多就提前几分钟到站台，别等车停稳了才找舱门。

![首尔到 T1 的深夜巴士线路图与中途停靠站](./images/1.webp)

## 票价：10,000 韩元与 18,000 韩元两档

票价按线路分两档，差距刚好一倍。

| 线路 | 成人 | 儿童 |
| --- | --- | --- |
| N6000、N6001、N6002 | 10,000 韩元 | 8,000 韩元 |
| N6701、N6703 | 18,000 韩元 | 12,000 韩元 |

松亭站是一个例外：从这一站上车，成人 5,000 韩元、儿童 4,000 韩元，因为已经接近机场。住在盐仓、松亭一带，可以先到松亭站再上车，省下的钱不少。

价格是 2026 年 10 月的参考价，调整以现场和官网为准。买票可以用站台的自动售票机、便利店，也可以上车后向司机购买，具体以现场为准；深夜时段售票窗口多半已经关闭。

## 从首尔出发：发车时刻

首尔到机场方向的班次是固定的，晚上十点半之后陆续发出，末班在 03:20 前后从市区开走。

| 线路 | 首尔发车点 | 发车时刻 | 抵达时刻 |
| --- | --- | --- | --- |
| N6000 | 江南高速巴士客运站 | 22:30 / 23:20 / 00:10 / 01:10 / 02:00 / 02:50 | T1 23:40 / 00:30 / 01:20 / 02:20 / 03:10 / 04:00 |
| N6001 | 首尔站 | 22:55 / 23:45 / 00:40 / 01:35 / 02:25 / 03:20 | T1 00:05 / 00:55 / 01:50 / 02:45 / 03:35 / 04:30 |
| N6002（1 车）| 江南高速巴士客运站 | 23:40 | T2 01:10 |
| N6002（2 车）| 首尔站 | 03:00 | T2 04:30 |
| N6701 | 东大门设计广场（DDP）| 23:10 / 01:05 / 03:15 | T1 00:30 / 02:25 / 04:35；T2 00:50 / 02:45 / 04:55 |
| N6703 | 蚕室乐天世界 | 23:20 / 01:15 / 03:20 | T1 00:35 / 02:30 / 04:35；T2 00:55 / 02:50 / 04:55 |

表里有两个细节。同一班车先到 T1 再到 T2，两站相差约 20 分钟，去 T2 的话按后一个时刻安排。N6701、N6703 一晚只有三班，错过一班要等近两小时，赶飞机时别把时间压得太紧。

还要注意，表上的发车时刻是从起点站开出的时间，不是经过中途站的时间。在中途站上车，要按起点站的时刻再加十几到二十几分钟，站越远越晚；拿不准就在官网按站点查。

## 中途站与机场落客位置

首尔的发车站之外，巴士沿途还会停几站，具体位置和走向按线路不同。

| 线路 | 首尔沿途停靠 | 机场落客 |
| --- | --- | --- |
| N6000 | 江南高速巴士客运站 → 黑石站 → 盐仓站 → 松亭站 | T1 1 层 6A |
| N6001 | 首尔站 → 新龙山站 → 盐仓站 → 松亭站 | T1 1 层 6A；部分班次仅到 T2 B1 24 号 |
| N6002（1 车）| 江南高速巴士客运站 → 黑石站 → 盐仓站 → 松亭站 | T2 B1 24 号 |
| N6002（2 车）| 首尔站 → 新龙山站 → 盐仓站 → 松亭站 | T2 B1 24 号 |
| N6701 | 东大门设计广场（DDP）→ 乙支路入口 → 首尔站 → 麻浦站 | T1 3 层 3B；T2 B1 18 号 |
| N6703 | 蚕室乐天世界 → COEX → 瑞来村 | T1 3 层 3B；T2 B1 19 号 |

落客位置按航站楼分开。T1 的 6A 在 1 层到达层外侧，3B 在 3 层出发层；T2 的地下一层是交通中心，出电梯就能看到站台。下车后跟着航站楼的指示牌走，办登机牌的地方在出发层。

T2 的交通中心地下一层同时是机场铁路和巴士的换乘层，站台编号就是门牌号，按数字找过去即可。T1 的 1 层门外就是普通巴士与机场大巴的落客点，下车直接进到达厅，不用再穿行。

## 反向：从机场回市区怎么查

机场落地后要进首尔，方向相反，线路和时刻不是同一套。这份资料只覆盖首尔到机场，机场到市区的深夜巴士请查仁川机场官网：交通与停车 → 公共交通 → 巴士 → 深夜巴士（第 1 航站楼）→ 首尔深夜巴士，页面地址是 [airport.kr/ap_ch/1702](https://www.airport.kr/ap_ch/1702/subview.do)。

官网按航站楼分列，能看到当季的线路、发车时刻和站台号，比任何二手整理都准。落地后先看清自己从 T1 还是 T2 出来，再对页面上的站台位置。如果赶不上末班深夜巴士，机场铁路的首班车在 05:15 前后，在机场等两三个小时也能进城；不想等就打车。

## 深夜乘车的几点提醒

深夜巴士的班次密度远低于白天，多数线路一晚只有三到六班，N6002 只有两班，错过一班往往要等一小时以上。落地时间接近末班，最好在飞机上就把入境和取行李的时间算进去；赶不上，就只剩出租车。

出租车是深夜的兜底方案。仁川机场到首尔市区按距离计价，夜间还有加成，费用明显高于巴士，但门到门、不用等。几个人同行、行李又多的话，打车反而更划算。

还有两点。深夜线路的支付方式以现场为准，上车前把现金或交通卡准备好；巴士在市区沿途停靠，报站以韩语为主，不确定在哪一站下，可以提前把站名写给司机看。

还有一种情况：航班延误到凌晨，原定那班巴士已经开走。先在官网核对还有没有后续班次，没有就按出租车的预算走，别在站台上等一个不会来的班次。
