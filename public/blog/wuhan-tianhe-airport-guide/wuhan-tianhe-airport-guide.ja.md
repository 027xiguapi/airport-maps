夏休みの終わりと帰省ラッシュが重なり、武漢天河国際空港は一年で最も混雑する時期を迎えています。このガイドでは、第2・第3ターミナルの実用的な情報を**国内線の出発**、**国内線の到着**、**空港へのアクセスと空港からの移動**、**駐車場**の4つに分けて説明します。

天河空港には現在、**第3ターミナル**（出発は4階、到着は2階）と**第2ターミナル**（出発は2階、到着は1階）の2つのターミナルが稼働しています。出発前にご利用の便がどちらのターミナルかを確認してください。両ターミナル間は**空港バス3号線**が往復しています。本記事のターミナル図と駐車場の経路図は、空港公式サイトのものです。

## 1. 国内線の出発

### 第3ターミナル

1. **ターミナルに到着します。** 出発の2時間前に到着し、航空会社でターミナルを確認してください。第3ターミナルの出発フロアは4階です。
2. **チェックインと荷物の預け入れ。** チェックインと手荷物はE・F・J・Kのチェックインアイランドで扱います。チェックインは出発の**30分前**に締め切られるため、余裕を持って進めてください。セルフチェックインとセルフ荷物預けも利用できますが、事前にオンラインチェックインを済ませておくと安心です。
3. **保安検査。** 搭乗券と身分証明書またはパスポートを用意し、保安検査員に提示してください。
4. **待機と搭乗。** フライト情報画面と案内表示に従い、出発の**30〜40分前**にはゲートに到着してください。

### 第2ターミナル

1. **ターミナルに到着します。** 出発の2時間前に到着し、航空会社でターミナルを確認してください。第2ターミナルの出発フロアは2階です。
2. **チェックインと荷物の預け入れ。** チェックインと手荷物はA・Bのチェックインアイランドで扱います。チェックインは出発の**30分前**に締め切られるため、余裕を持って進めてください。セルフチェックインとセルフ荷物預けも利用できますが、事前にオンラインチェックインを済ませておくと安心です。
3. **保安検査。** 搭乗券と身分証明書またはパスポートを用意し、保安検査員に提示してください。
4. **待機と搭乗。** フライト情報画面と案内表示に従い、出発の**30〜40分前**にはゲートに到着してください。

![第2ターミナルのフロアマップと旅客動線](./images/1.webp)

## 2. 国内線の到着

### 第3ターミナル

1. **到着。** 出迎えがある場合は、ご利用の便が到着するターミナルを事前に伝えてください。第3ターミナルの到着フロアは2階です。
2. **手荷物を受け取ります。** 情報画面でご利用の便のターンテーブルを確認してください。荷物の取り違えを防ぐため、スタッフが手荷物タグと搭乗券のバーコードを照合することがあります。手荷物引換証を手元に用意し、確認にご協力ください。
3. **空港を出ます。** ご自身の安全と治安のため、制限区域外で空港の公式IDを持たない人からのサービスを受けたり、無許可で客引きをする運転手の車に乗ったりしないでください。

![第3ターミナル2階（到着）のフロアマップ](./images/2.webp)

### 第2ターミナル

1. **到着。** 出迎えがある場合は、ご利用の便が到着するターミナルを事前に伝えてください。第2ターミナルの到着フロアは1階です。
2. **手荷物を受け取ります。** 情報画面でご利用の便のターンテーブルを確認し、同様に抜き取り確認にご協力ください。
3. **空港を出ます。** 制限区域外で空港の公式IDを持たない人からのサービスを受けたり、無許可の車に乗ったりしないでください。

![第2ターミナル到着階と手荷物受取所のフロアマップ](./images/3.webp)

## 3. 空港へのアクセスと空港からの移動

天河空港の地上交通は、**空港バス**、**地下鉄2号線**、**空港バス3号線**、**鉄道駅**を中心に組み立てられています。両ターミナル間、およびターミナルと交通センターの間の連絡路にはすべて案内表示があります。

### 空港バス

- **運行時間：** 毎日8時30分から最終便まで。オンラインでは「天河畅行」（Tianhe Changxing）ミニプログラムから注文できます。
- **運行間隔：** 最終便まで30分おき。
- **窓口での購入：** 第2ターミナル1階9〜10番ゲート、第3ターミナル12番ゲート内。
- **カスタマーサービス：** 13387631827

| 路線 | 停車地（運賃） |
| --- | --- |
| 1号線 | T3 / T2 → 園博園北（地下鉄、10元）→ 民航住宅区（10元）→ 漢口駅（12元）→ CBD財富中心・泛海（12元）→ 青年路（12元）→ 古琴台（15元）→ 首義広場（18元）→ 武昌駅（20元）→ 武商夢時代（20元、この停留所の切符は21時30分から販売） |
| 2号線 | T3 / T2 → 楊汊湖（10元）→ 金橋イオン（10元）→ 黄浦路／工農兵路（12元）→ 徐東ショッピングモール（15元）→ 岳家嘴（15元）→ 東亭（18元）→ 楚河漢街（20元）→ 洪山広場（20元）→ 武漢駅（45元） |
| 空港・鉄道連絡バス | 武漢天河国際空港 ⇄ 武漢駅、直行・無料（暫定運行、09:25〜17:55）。切符の購入と乗車場所は空港バスと同じ |

### 長距離バス

出発時刻と路線はカスタマーサービスに電話でお問い合わせください。窓口販売の時刻表が正式な情報です。切符は空港バスと同じ場所（第2ターミナル1階9〜10番ゲート、第3ターミナル12番ゲート内）で購入でき、問い合わせ先は13387631827です。

### 地下鉄2号線

- **運行時間：** 平日は06:00〜23:00、祝日は06:30〜23:00。列車は5〜8分間隔。
- 武漢地下鉄の公式アナウンスが優先します。

空港へのアクセスと空港からのルート：

- **T3出発へ：** 地下鉄2号線で天河空港駅へ → B出口 → 交通センター2階、連絡通路1・2・3 → 第3ターミナル4階出発ロビー。
- **T3到着から：** 第3ターミナル2階到着ロビー → 2階6・7・8番ゲート → 地下鉄B出口 → 地下鉄2号線。
- **T2出発へ：** 地下鉄2号線で天河空港駅へ → B出口 → 交通センター2階、連絡通路1・2・3 → 第3ターミナル12番ゲート外 → 空港バス3号線に乗り換え → 第2ターミナル7番ゲート → 2階出発ロビー。
- **T2到着から：** 第2ターミナル1階到着ロビー → 1階10番ゲートの停留所 → 空港バス3号線に乗り換え → 第3ターミナル12番ゲート → 交通センター2階、連絡通路1・2・3 → 地下鉄B出口 → 地下鉄2号線。

### 空港バス3号線（ターミナル間シャトル）

- **停留所：** 第3ターミナル12番ゲート（降車・乗車）→ 第2ターミナル1階7番ゲート（降車）→ 第2ターミナル1階10番ゲート（乗車）→ 第3ターミナル12番ゲート（降車・乗車）。
- **運行間隔：** 約5分おき。
- **運行時間：** 06:00〜23:00。

### 鉄道

天河空港駅からの列車は、武漢市内の漢口駅・武昌駅のほか、省内のいくつかの都市に停車します。鉄道事業者の公式アナウンスが優先します。

- **T3出発へ：** 天河空港駅に到着 → C出口 → 交通センター2階、連絡通路1・2・3 → 第3ターミナル4階出発ロビー。
- **T3到着から：** 第3ターミナル2階到着ロビー → 2階6・7・8番ゲート → C出口 → 天河空港駅。
- **T2出発へ：** 天河空港駅に到着 → 地下鉄B出口 → 交通センター2階、連絡通路1・2・3 → 第3ターミナル12番ゲート外 → 空港バス3号線に乗り換え → 第2ターミナル7番ゲート → 2階出発ロビー。
- **T2到着から：** 第2ターミナル1階到着ロビー → 1階10番ゲートの停留所 → 空港バス3号線に乗り換え → 第3ターミナル12番ゲート → 交通センター2階、連絡通路1・2・3 → C出口 → 天河空港駅。
