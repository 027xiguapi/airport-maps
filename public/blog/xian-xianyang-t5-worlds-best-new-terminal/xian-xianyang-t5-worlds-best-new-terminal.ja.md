西安咸陽国際空港（XIY）の第5ターミナルが、2025年Skytraxワールド・エアポート・アワードの「世界最高の新空港ターミナル」部門で2位に選ばれました。同じ回の結果で、空港はSkytraxの「中国地域空港」ランキングで5位に入っています。空港がこの結果を地元メディアに伝え、メディアは2026年3月20日に報じました。

この2つの順位は、測っているものが違います。ターミナル部門は1つの新しい建物を評価します。空間が機能するか、旅客動線が効率的か、施設が旅客の評価表に耐えるか。地域空港部門は、サービスや運用を含めた空港全体を評価します。旅客にとって前者は、新しいシステムを備えた新しいターミナルを出発・到着する可能性が高いという意味です。後者は、この規模の空港の中でも、そのプロセスが上位にあるという意味です。以下では、2つの結果を分け、Skytraxがどう評価に至るか、第5ターミナルが空港の拡張のどこに位置するかを整理します。

## 2つの結果、2つの異なる競争

「世界最高の新空港ターミナル」部門は、近年開業したターミナルを対象とし、評価は旅客が行います。空間が機能するか、動線が短いか、施設が揃っているか。発表時に公表された2025年の結果表は、トップ5を次のように挙げています。

| 2025年 世界最高の新空港ターミナル | 空港とターミナル |
| --- | --- |
| 1 | アルマトイ 第2ターミナル（カザフスタン） |
| 2 | 西安咸陽 第5ターミナル（中国） |
| 3 | リヤド 第1ターミナル（サウジアラビア） |
| 4 | セント・マーチン |
| 5 | ルアンダ（アンゴラ） |

つまり新ターミナル部門では、第5ターミナルが世界2位となり、アルマトイ第2ターミナルの後、リヤド第1ターミナル、セント・マーチン、ルアンダの前に位置しました。

「中国地域空港」ランキングは、中国の地域空港を対象に、サービス、運用、管理を含めて空港全体を採点します。同じ2025年の結果表は、トップ10を次のように挙げています。

| 2025年 中国地域空港 | 空港（発表どおり） |
| --- | --- |
| 1 | 海口美蘭 |
| 2 | 三亜鳳凰 |
| 3 | 長沙 |
| 4 | 厦門 |
| 5 | 西安 |
| 6 | 杭州 |
| 7 | 青島 |
| 8 | 昆明 |
| 9 | 武漢 |
| 10 | 天津浜海 |

西安は5位で、海口美蘭、三亜鳳凰、長沙、厦門の後、杭州、青島、昆明、武漢、天津浜海の前に位置しました。この規模の西部のハブとしては、同規模の空港の中でも上位グループに入ります。

## Skytraxはどう評価に至るか

空港によれば、Skytraxは航空会社と空港のサービス品質について最も権威ある評価機関の一つで、その結果は100カ国以上、500を超える空港を対象とした実際の旅客満足度調査に基づいています。毎年のランキングは業界で信頼できる基準として広く受け止められています。

それが2種類の賞の性格を決めます。新ターミナル部門は第一印象に大きく左右されます。空間が使いやすいか、歩いて疲れないか、案内表示がわかりやすいか、座席と電源コンセントが足りているか。地域空港部門は長期的な実績に左右されます。ピーク時の列の長さ、荷物が確実に届くか、スタッフが問題にどう対応するか。前者は開業後まもなく取れますが、後者には年数がかかります。両方を取ったということは、新しいハードと日々の運用の間に目立った隔たりがないことを示します。

## 拡張計画の核としての第5ターミナル

第5ターミナルは空港のハブ拡張計画の目玉であり、開業以来注目を集めてきました。空港によれば、この建物は先を見据えた空間計画、効率的な旅客動線、人間中心の施設によってリスト入りし、西安の新たな空の名刺だと表現しています。

その言葉の背後には、ターミナルと空港の単純な関係があります。処理能力のボトルネックは滑走路ではなく、チェックイン、保安検査、手荷物処理、搭乗にあることが少なくありません。全員が同じ時間に同じ建物へ来ると、カウンター、レーン、ターンテーブルが制約になります。新しいターミナルは床面積を増やすだけでなく、プロセスを組み直す機会をもたらします。チェックインアイランド、保安検査レーン、手荷物システム、ゲートを、古い建物に押し込むのではなく、新しい交通モデルに合わせて配置できるのです。

## 旅客にとっての意味

近いうちに西安から飛行機で出発するなら、実務上の変化はターミナルです。第5ターミナルは新しいため、施設も、チェックイン、保安検査、出発ラウンジを通る流れも新しくなっています。空港は引き続き複数のターミナルを同時に運用しているので、出発前にフライト情報でターミナルを確認してください。間違った建物に着いてしまうのは、複数ターミナルの空港で最もよくある失敗です。

![第5ターミナルのチェックインロビー。国際線と地域線のアイランドが並びます](./images/3.webp)

2つ目のポイントは期待値についてです。中国の地域空港で5位という順位は、航空券を安くしたり保安検査の列を短くしたりはしませんが、読み取る価値のあるシグナルです。この規模の空港としては、ここのサービスプロセスに対する旅客の評価が高いということです。旅を実際に左右するのは、今もスケジュール、書類、そして空港にどれだけ早く着くかです。十分な余裕を残すことが、どんなトロフィーよりも旅の役に立ちます。

空港は今後もサービス革新と、地域文化を建物に取り入れる取り組みへの投資を続けるとしています。旅客にとっての試金石は単純です。次に第5ターミナルから出発するとき、チェックイン、保安検査、ゲートまでの歩行がどれだけスムーズかということです。
