从都柏林飞巴黎，落地戴高乐。出发前查了很多「法国入境会不会问很多问题」「材料要不要准备一叠」，结果从下机到走出到达口，几乎没有停顿。真正让人意外的不是速度，而是流程本身已经和旧攻略里写的不一样了：护照上没有章，官员也不打算盖。

这篇按落地后的顺序记录：先看中文指示牌怎么走，再过边检，然后解释为什么不再盖章，最后说清过关之后最该做的一件事。戴高乐机场是法国最大的国际机场，三个航站楼加上 T2 的七个子楼，第一次来确实容易把「转机」和「出口」看混；好在这里的中文指引做得相当完整，语言不是障碍，流程才是。

需要先说明的是，这是一次个人经历，不是官方流程说明。边检的询问、抽查和通道安排由现场决定，不同航班、不同时段可能完全不同。文中提到的材料清单，是「准备了但没被看」，不是「不需要准备」。

## 一、落地后的中文指引

机舱门一开，第一块牌子就是三语并排的：「Correspondances / Transfer / 转机」「Sortie / Exit / 出口」「Bagages / Baggage / 行李提取」。不需要先认出哪个是法语词，跟着「出口」两个字走也能走对。这趟从都柏林飞过来，最直接的感受是中文不是零星点缀，而是从廊桥、走廊、边检一直铺到行李厅的完整指引——连廊桥的玻璃门上都贴着「Sortie / Exit / 出口」的圆形贴纸，旁边四个箭头指向出口方向。

![廊桥玻璃上的「Sortie / Exit / 出口」圆形贴纸与四个箭头，窗外是停着行李车的停机坪，左上角是绿色出口标志](./images/1.webp)

从廊桥出来是一段长长的玻璃走廊，左边是停机坪和廊桥，右边是航站楼，人只能顺着往前走，尽头才是分流点。这一段没有岔路，跟着人流和黄色指示牌走就行，不用急着找电梯或地铁标志。

![玻璃连廊里旅客背着包往前走，左侧窗外是停机坪、廊桥和机场控制塔](./images/2.webp)

真正的选择出现在第一块悬挂牌前：转机走 Correspondances，取行李走 Bagages，直接出机场走 Sortie。牌子会把三个词和图标排在一起，转机是两个相反方向的小人，出口是一个走路的人，行李是传送带的形状；即使不认识法语，也能靠图标判断。

中文的覆盖范围还包括登机口、值机区、洗手间和行李转盘，这一点在夜间抵达、人少、又累的时候特别有用。但要注意：指示牌有中文，不代表工作人员会说中文。边检和海关的对话仍以法语、英语为主，把酒店地址、行程和回程日期存在手机里，必要时直接把屏幕递给对方看，比现场组织句子有效。

## 二、边检：护照、签证与分流

从分流牌到边检口还有一段路，沿途的悬挂牌会反复出现同样的三个词。看到「Portes 40-68」这类登机口编号时不要跟着走，那是给转机旅客去登机口的方向，不是入境通道；认准「Contrôle des passeports」，或者干脆跟着走非欧盟通道的人流。

![悬挂指示牌：Correspondances / Transfer / 转机、Sortie / Exit / 出口、Bagages / Baggage / 行李提取，各配一个走路小人图标](./images/3.webp)

![头顶指示牌：左侧是 Bagages / 行李提取、Sortie / 出口、Correspondances / 转机，右侧是「Portes / Gates 40-68 登机口」和一个向下的箭头](./images/4.webp)

边检前的分流从「看护照」开始。临近边检区域会有工作人员站在通道口，扫一眼你手上的护照封面，用手势把你指向对应的队伍：欧盟、欧洲经济区护照走一边，其他护照走另一边。持中国护照加申根签证的旅客走非欧盟通道，不需要自己判断哪条队更快，跟着工作人员的指示最稳。

轮到柜台，把护照翻到有申根签证的那一页递进去。实际经历是：对方没有说话，打开护照、看了一眼签证，示意录指纹，录完把护照递回来，挥手让走。没有问来做什么、住哪里、待几天，也没有要求出示酒店订单和回程机票。出发前特意准备的住宿确认、回程或后续行程机票、行程单和旅行保险，一份都没有被看。

![边检区的玻璃隔间与 01、02、03 号柜台，头顶牌子指向「Portes 60-68」，一名穿深色衣服的旅客正从通道里走出来](./images/5.webp)

这不等于可以空手过关。官员有裁量权，抽查是随机的；材料放在随身包里、手机里留一份电子版，被问到时能立刻拿出来，才是正确的心态。真正要避免的是把证件塞进托运箱——一旦被要求出示，你只能站在柜台前翻箱子。

指纹是按提示现场采集的：把手指放在读取器上，通常先右手四指，再左手四指，最后两个拇指，机器上有图示和中文或英文提示，跟着做即可。采集完等屏幕提示通过，再拿回护照。如果手指干燥或刚涂过护手霜，读取可能失败，现场擦一下手再试，不用紧张。

边检官员的问题通常很朴素：来法国做什么、停留几天、还去哪些国家、住在哪里、什么时候离境。回答与机票、酒店和行程一致就行，不需要背台词，也不要把行程说得比实际复杂。旅游就答旅游，转机就答转机；含糊其辞比答案简单更容易引起追问。

## 三、EES 之后：为什么不再盖章

递上护照时特意问了一句能不能盖章，得到的回答是一个干脆的「no」。这不是敷衍，也不是工作人员心情不好，而是制度变了：法国已经用 EES 取代了过去的入境章。

EES 是欧盟的「入境／出境系统」（Entry/Exit System），2025 年 10 月起分阶段启用，把过去「排队—盖章—放行」的流程，换成「第一次入境登记生物信息—之后靠记录核验」。短期旅客（包括持申根签证的中国护照持有人）在第一次入境时，要在边检采集护照资料、面部照片和指纹；这些信息会在系统里保留一段时间，之后再入境，官员调出记录就能确认你的出入境时间，不再需要在护照上盖一个日期章。

所以，护照上干干净净，不代表没有入境记录；主动要求盖章，也基本会被拒绝，因为系统里已经没有这个动作。很多人翻到旧攻略里写「排队→海关盖章→问几句」，发现现场完全不是这样，会怀疑自己走错了通道——其实只是流程换了一代。

不盖章还有一个实际后果：以后办理居留、续签、学校注册，或者需要证明某次入境日期时，护照上的章帮不上忙。登机牌、电子行程单、酒店记录反而更可靠，落地后别急着把它们删掉，至少留到这一趟行程结束。

还需要知道，EES 是整个申根区统一的系统，不是法国单独加的环节。你从哪个国家第一次进入申根区，就在哪里登记；之后再去别的申根国家，走的是同一个记录。这也是为什么有些人在德国、荷兰转机时已经被采集过指纹，到法国反而什么也不用做。

## 四、过关之后的第一件事

过了边检，走廊会把人送进行李厅，头顶的牌子换成「Bagages / Baggage / 行李提取」和「Sortie / Exit / 出口」，传送带上方挂着转盘编号。取完行李，推着车走向出口，出口前会经过海关通道，一般分绿色（无申报）和红色（有申报）两条。这次没有遇到开箱检查，但抽查是随机的，走绿色通道不代表不会被叫住。

![行李厅：5 号转盘旁的传送带、成排行李推车，悬挂牌写着「Sortie / Exit / 出口」并带向下箭头](./images/6.webp)

出来以后，第一件事是解决交通。戴高乐机场的交通卡在机场就能买：RER B 车站的黄色「Tickets et Navigo」机器、SNCF 柜台，都能买到实体卡或单程票。如果目的地是巴黎市区、停留几天，可以按天数在单程票、日票和周卡之间选；周卡在机场买不到，要进城到人工柜台办，这一点最好提前知道，免得在机器前反复找。

更实际的做法是：能用 Île-de-France Mobilités 的 App 买、再绑进 Apple Wallet，就尽量用 App——省下制卡费，也省去排队。代价是注册通常需要一个欧洲手机号，没有的话还是老老实实买实体卡。

![深蓝色指示墙：向左箭头下依次是 Sortie / Exit / 出口、Transports / Ground Transportation / 地面交通、Correspondances / Transfer / 转机](./images/7.webp)

找路时先看楼层。戴高乐的到达层、火车站层和出发层是分开的，电梯口的牌子会把「5 到达」「2 火车站」和 RER B 标志排在一起，右侧列出出租车、酒店、洗手间和停车场；看清层数再按电梯，比在航站楼里绕圈快得多。

![电梯口楼层牌：5 层 Arrivées / Arrivals / 到达、2 层 Gare / Train Station / 火车站与 RER B 标志，右侧列出出租车、酒店、洗手间与停车场](./images/8.webp)

车站大厅的混凝土拱顶下，一排「Tickets et Navigo」机器和 Relay 便利店挨在一起，买票、买水、买转换插头都能在这一层解决。如果目的地不是巴黎，而是里昂、波尔多、马赛，也可以从机场 T2 地下高铁站直接走，不必先进城再折返；买票前看清车票上的出发站，别把「巴黎某站」和「机场 TGV 站」弄混。

![车站大厅：混凝土拱顶与斜柱下，一排「Tickets et Navigo」售票机和 Relay 便利店](./images/9.webp)

## 五、几个容易误判的细节

第一，自助闸机不是给所有人用的。边检区旁边有一排自动通道，欧盟护照、法国居留卡持有人可以自助通关；持中国护照的短期旅客通常不适用。看到前面的人刷护照就过，不要跟着走，跟着工作人员的指引去人工柜台，省得在闸机前被拦下再退回来。

第二，不问不等于不查。这次没有被问问题，也没有被要求出示材料，但官员完全可以在下一班航班上问得更细。把护照、签证、住宿、回程票和保险放在随身包的同一个夹层里，需要时一次拿出来，比分开找要体面得多。

第三，航站楼之间的距离不短。戴高乐有 T1、T2、T3 三座航站楼，T2 还分成 A 到 G 七个子楼；转机或换航站楼要坐免费的 CDGVAL，加上走路和等车，留 30 分钟以上比较稳妥。转机时间紧，先在登机口确认行李是否直挂，再决定要不要出关。

第四，出口和接机要说到具体编号。戴高乐的出口按航站楼和到达层分区，光说「到戴高乐接我」没有用；把 Terminal、Hall 和出口编号发给接机的人，对方才能把车停在正确的位置。出口外就是长途大巴和机场巴士的站台，蓝色方柱上写着 QUAI C、D、E，木质雨棚下还有 B3 之类的编号。

![航站楼外的长途大巴站台：蓝色方柱上写着 QUAI C、QUAI D、QUAI E，头顶是混凝土高架](./images/10.webp)

![木质格栅雨棚下的 B3 大巴站台，钢柱支撑，远处是酒店大楼与停放的车辆](./images/11.webp)

第五，语言上的准备比想象中重要。指示牌有中文，边检和海关却不一定有；一句「Bonjour」开头，递护照时把签证页翻好，回答时看着对方、说慢一点，比背一长串句子有用。真遇到听不懂的问题，可以请对方重复，或者把手机里的行程递过去。

把这些串起来看，戴高乐入境其实只有三件事：跟着中文指示牌走到边检，按工作人员的分流递上护照和签证，过关后先解决交通再出机场。这次从都柏林落地，整体感受就是「丝滑」两个字——但丝滑来自流程本身已经简化，不是来自运气。2026 年 8 月有旅客这样走了一趟，边检流程、EES 登记方式与交通票价都可能调整，出发前请以法国官方与机场当日公布的信息为准。
