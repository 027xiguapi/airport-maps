從都柏林飛巴黎，落地戴高樂。出發前查了很多「法國入境會不會問很多問題」「材料要不要準備一疊」，結果從下機到走出到達口，幾乎沒有停頓。真正讓人意外的不是速度，而是流程本身已經和舊攻略裡寫的不一樣了：護照上沒有章，官員也不打算蓋。

這篇按落地後的順序記錄：先看中文指示牌怎麼走，再過邊檢，然後解釋為什麼不再蓋章，最後說清過關之後最該做的一件事。戴高樂機場是法國最大的國際機場，三個航廈加上 T2 的七個子樓，第一次來確實容易把「轉機」和「出口」看混；好在這裡的中文指引做得相當完整，語言不是障礙，流程才是。

需要先說明的是，這是一次個人經歷，不是官方流程說明。邊檢的詢問、抽查和通道安排由現場決定，不同航班、不同時段可能完全不同。文中提到的材料清單，是「準備了但沒被看」，不是「不需要準備」。

## 一、落地後的中文指引

機艙門一開，第一塊牌子就是三語並排的：「Correspondances / Transfer / 轉機」「Sortie / Exit / 出口」「Bagages / Baggage / 行李提取」。不需要先認出哪個是法語詞，跟著「出口」兩個字走也能走對。這趟從都柏林飛過來，最直接的感受是中文不是零星點綴，而是從廊橋、走廊、邊檢一直鋪到行李廳的完整指引——連廊橋的玻璃門上都貼著「Sortie / Exit / 出口」的圓形貼紙，旁邊四個箭頭指向出口方向。

![廊橋玻璃上的「Sortie / Exit / 出口」圓形貼紙與四個箭頭，窗外是停著行李車的停機坪，左上角是綠色出口標誌](./images/1.webp)

從廊橋出來是一段長長的玻璃走廊，左邊是停機坪和廊橋，右邊是航廈，人只能順著往前走，盡頭才是分流點。這一段沒有岔路，跟著人流和黃色指示牌走就行，不用急著找電梯或地鐵標誌。

![玻璃連廊裡旅客揹著包往前走，左側窗外是停機坪、廊橋和機場控制塔](./images/2.webp)

真正的選擇出現在第一塊懸掛牌前：轉機走 Correspondances，取行李走 Bagages，直接出機場走 Sortie。牌子會把三個詞和圖示排在一起，轉機是兩個相反方向的小人，出口是一個走路的人，行李是傳送帶的形狀；即使不認識法語，也能靠圖示判斷。

中文的覆蓋範圍還包括閘口、值機區、洗手間和行李轉盤，這一點在夜間抵達、人少、又累的時候特別有用。但要注意：指示牌有中文，不代表工作人員會說中文。邊檢和海關的對話仍以法語、英語為主，把酒店地址、行程和回程日期存在手機裡，必要時直接把螢幕遞給對方看，比現場組織句子有效。

## 二、邊檢：護照、簽證與分流

從分流牌到邊檢口還有一段路，沿途的懸掛牌會反覆出現同樣的三個詞。看到「Portes 40-68」這類閘口編號時不要跟著走，那是給轉機旅客去閘口的方向，不是入境通道；認準「Contrôle des passeports」，或者乾脆跟著走非歐盟通道的人流。

![懸掛指示牌：Correspondances / Transfer / 轉機、Sortie / Exit / 出口、Bagages / Baggage / 行李提取，各配一個走路小人圖示](./images/3.webp)

![頭頂指示牌：左側是 Bagages / 行李提取、Sortie / 出口、Correspondances / 轉機，右側是「Portes / Gates 40-68 閘口」和一個向下的箭頭](./images/4.webp)

邊檢前的分流從「看護照」開始。臨近邊檢區域會有工作人員站在通道口，掃一眼你手上的護照封面，用手勢把你指向對應的隊伍：歐盟、歐洲經濟區護照走一邊，其他護照走另一邊。持中國護照加申根簽證的旅客走非歐盟通道，不需要自己判斷哪條隊更快，跟著工作人員的指示最穩。

輪到櫃檯，把護照翻到有申根簽證的那一頁遞進去。實際經歷是：對方沒有說話，開啟護照、看了一眼簽證，示意錄指紋，錄完把護照遞回來，揮手讓走。沒有問來做什麼、住哪裡、待幾天，也沒有要求出示酒店訂單和回程機票。出發前特意準備的住宿確認、回程或後續行程機票、行程單和旅行保險，一份都沒有被看。

![邊檢區的玻璃隔間與 01、02、03 號櫃檯，頭頂牌子指向「Portes 60-68」，一名穿深色衣服的旅客正從通道里走出來](./images/5.webp)

這不等於可以空手過關。官員有裁量權，抽查是隨機的；材料放在隨身包裡、手機裡留一份電子版，被問到時能立刻拿出來，才是正確的心態。真正要避免的是把證件塞進託運箱——一旦被要求出示，你只能站在櫃檯前翻箱子。

指紋是按提示現場採集的：把手指放在讀取器上，通常先右手四指，再左手四指，最後兩個拇指，機器上有圖示和中文或英文提示，跟著做即可。採集完等螢幕提示通過，再拿回護照。如果手指乾燥或剛塗過護手霜，讀取可能失敗，現場擦一下手再試，不用緊張。

邊檢官員的問題通常很樸素：來法國做什麼、停留幾天、還去哪些國家、住在哪裡、什麼時候離境。回答與機票、酒店和行程一致就行，不需要背臺詞，也不要把行程說得比實際複雜。旅遊就答旅遊，轉機就答轉機；含糊其辭比答案簡單更容易引起追問。

## 三、EES 之後：為什麼不再蓋章

遞上護照時特意問了一句能不能蓋章，得到的回答是一個乾脆的「no」。這不是敷衍，也不是工作人員心情不好，而是制度變了：法國已經用 EES 取代了過去的入境章。

EES 是歐盟的「入境／出境系統」（Entry/Exit System），2025 年 10 月起分階段啟用，把過去「排隊—蓋章—放行」的流程，換成「第一次入境登記生物資訊—之後靠記錄核驗」。短期旅客（包括持申根簽證的中國護照持有人）在第一次入境時，要在邊檢採集護照資料、面部照片和指紋；這些資訊會在系統裡保留一段時間，之後再入境，官員調出記錄就能確認你的出入境時間，不再需要在護照上蓋一個日期章。

所以，護照上乾乾淨淨，不代表沒有入境記錄；主動要求蓋章，也基本會被拒絕，因為系統裡已經沒有這個動作。很多人翻到舊攻略裡寫「排隊→海關蓋章→問幾句」，發現現場完全不是這樣，會懷疑自己走錯了通道——其實只是流程換了一代。

不蓋章還有一個實際後果：以後辦理居留、續簽、學校註冊，或者需要證明某次入境日期時，護照上的章幫不上忙。登機牌、電子行程單、酒店記錄反而更可靠，落地後別急著把它們刪掉，至少留到這一趟行程結束。

還需要知道，EES 是整個申根區統一的系統，不是法國單獨加的環節。你從哪個國家第一次進入申根區，就在哪裡登記；之後再去別的申根國家，走的是同一個記錄。這也是為什麼有些人在德國、荷蘭轉機時已經被採集過指紋，到法國反而什麼也不用做。

## 四、過關之後的第一件事

過了邊檢，走廊會把人送進行李廳，頭頂的牌子換成「Bagages / Baggage / 行李提取」和「Sortie / Exit / 出口」，傳送帶上方掛著轉盤編號。取完行李，推著車走向出口，出口前會經過海關通道，一般分綠色（無申報）和紅色（有申報）兩條。這次沒有遇到開箱檢查，但抽查是隨機的，走綠色通道不代表不會被叫住。

![行李廳：5 號轉盤旁的傳送帶、成排行李推車，懸掛牌寫著「Sortie / Exit / 出口」並帶向下箭頭](./images/6.webp)

出來以後，第一件事是解決交通。戴高樂機場的交通卡在機場就能買：RER B 車站的黃色「Tickets et Navigo」機器、SNCF 櫃檯，都能買到實體卡或單程票。如果目的地是巴黎市區、停留幾天，可以按天數在單程票、日票和周卡之間選；周卡在機場買不到，要進城到人工櫃檯辦，這一點最好提前知道，免得在機器前反覆找。

更實際的做法是：能用 Île-de-France Mobilités 的 App 買、再綁進 Apple Wallet，就儘量用 App——省下制卡費，也省去排隊。代價是註冊通常需要一個歐洲手機號，沒有的話還是老老實實買實體卡。

![深藍色指示牆：向左箭頭下依次是 Sortie / Exit / 出口、Transports / Ground Transportation / 地面交通、Correspondances / Transfer / 轉機](./images/7.webp)

找路時先看樓層。戴高樂的到達層、火車站層和出發層是分開的，電梯口的牌子會把「5 到達」「2 火車站」和 RER B 標誌排在一起，右側列出計程車、酒店、洗手間和停車場；看清層數再按電梯，比在航廈裡繞圈快得多。

![電梯口樓層牌：5 層 Arrivées / Arrivals / 到達、2 層 Gare / Train Station / 火車站與 RER B 標誌，右側列出計程車、酒店、洗手間與停車場](./images/8.webp)

車站大廳的混凝土拱頂下，一排「Tickets et Navigo」機器和 Relay 便利店挨在一起，買票、買水、買轉換插頭都能在這一層解決。如果目的地不是巴黎，而是里昂、波爾多、馬賽，也可以從機場 T2 地下高鐵站直接走，不必先進城再折返；買票前看清車票上的出發站，別把「巴黎某站」和「機場 TGV 站」弄混。

![車站大廳：混凝土拱頂與斜柱下，一排「Tickets et Navigo」售票機和 Relay 便利店](./images/9.webp)

## 五、幾個容易誤判的細節

第一，自助閘機不是給所有人用的。邊檢區旁邊有一排自動通道，歐盟護照、法國居留卡持有人可以自助通關；持中國護照的短期旅客通常不適用。看到前面的人刷護照就過，不要跟著走，跟著工作人員的指引去人工櫃檯，省得在閘機前被攔下再退回來。

第二，不問不等於不查。這次沒有被問問題，也沒有被要求出示材料，但官員完全可以在下一班航班上問得更細。把護照、簽證、住宿、回程票和保險放在隨身包的同一個夾層裡，需要時一次拿出來，比分開找要體面得多。

第三，航廈之間的距離不短。戴高樂有 T1、T2、T3 三座航廈，T2 還分成 A 到 G 七個子樓；轉機或換航廈要坐免費的 CDGVAL，加上走路和等車，留 30 分鐘以上比較穩妥。轉機時間緊，先在閘口確認行李是否直掛，再決定要不要出關。

第四，出口和接機要說到具體編號。戴高樂的出口按航廈和到達層分割槽，光說「到戴高樂接我」沒有用；把 Terminal、Hall 和出口編號發給接機的人，對方才能把車停在正確的位置。出口外就是長途大巴和機場巴士的站臺，藍色方柱上寫著 QUAI C、D、E，木質雨棚下還有 B3 之類的編號。

![航廈外的長途大巴站臺：藍色方柱上寫著 QUAI C、QUAI D、QUAI E，頭頂是混凝土高架](./images/10.webp)

![木質格柵雨棚下的 B3 大巴站臺，鋼柱支撐，遠處是酒店大樓與停放的車輛](./images/11.webp)

第五，語言上的準備比想像中重要。指示牌有中文，邊檢和海關卻不一定有；一句「Bonjour」開頭，遞護照時把簽證頁翻好，回答時看著對方、說慢一點，比背一長串句子有用。真遇到聽不懂的問題，可以請對方重複，或者把手機裡的行程遞過去。

把這些串起來看，戴高樂入境其實只有三件事：跟著中文指示牌走到邊檢，按工作人員的分流遞上護照和簽證，過關後先解決交通再出機場。這次從都柏林落地，整體感受就是「絲滑」兩個字——但絲滑來自流程本身已經簡化，不是來自運氣。2026 年 8 月有旅客這樣走了一趟，邊檢流程、EES 登記方式與交通票價都可能調整，出發前請以法國官方與機場當日公佈的資訊為準。
