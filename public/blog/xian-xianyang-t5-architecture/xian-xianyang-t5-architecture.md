2025 年 Skytrax 全球机场大奖揭晓后，西安咸阳国际机场 T5 航站楼拿到“全球最佳新机场航站楼”第二名（TOP2），机场同时位列“中国区最佳区域机场”第五名。多数报道把它当作一条服务评比的新闻，但对建筑设计行业来说，这份成绩单的分量在别处：一个具体的建筑作品，被放进了国际旅客的打分表。

T5 航站楼及综合交通中心项目由中建西北院设计，总建筑面积约 70.55 万平方米，建筑高度 47.5 米，主楼面宽 495 米、进深 252 米。下面按构型、屋顶、分区、交通四个层次，把这座楼的建筑逻辑讲清楚——它如何在“让飞机好停”“让人少走路”“让文化看得见”这几件常常互相拉扯的事之间找平衡。

## 一、先把几个数字读一遍

| 项目 | 数据 |
| --- | --- |
| 设计单位 | 中建西北院 |
| 总建筑面积 | 约 70.55 万平方米 |
| 建筑高度 | 47.5 米 |
| 主楼面宽 | 495 米 |
| 主楼进深 | 252 米 |
| 指廊构型 | 六指廊放射状（国内首例） |
| 设计年旅客吞吐量 | 8000 万人次 |

这组数字里最容易被忽略的是“面宽 495 米、进深 252 米”。它描述的是主楼这个巨大矩形的两条边，也直接决定了从门口到最远登机口的基本距离。

47.5 米的高度也值得一说：T5 是横向展开的，不是向上堆叠的。好处是流程平铺、旅客不必反复上下楼；坏处是距离变长，于是就有了下面的“指廊”问题。

## 二、六指廊放射状：为什么“手掌”比“长廊”好走

先解释两个词。航站楼临停机坪的一侧叫“空侧”，是过了安检之后、飞机停靠的区域；另一侧叫“陆侧”，是公共交通、车道边和值机大厅所在的区域。所谓“指廊”，就是从主楼伸向停机坪的候机廊道，旅客在指廊两侧的登机口上飞机。

传统航站楼常见“一”字形或“T”字形布局：一条长长的候机廊，机位沿廊道排开。这种布局施工简单，但旅客走到尽头要走很久，机位数量也受廊道长度限制。T5 采用的是国内首例的六指廊放射状构型：主楼在中间，六条指廊像手指一样向外伸出，整体像一只摊开的手掌。

这个构型主要解决两个问题。第一是“空侧岸线”——飞机要靠桥停靠，就需要沿建筑外墙布置近机位，外墙越长，能停的近机位越多。六条指廊把建筑与停机坪接触的外墙面积成倍放大，机位数量随之增加，旅客更多时候可以走廊桥，而不是坐摆渡车在机坪上绕。第二是步行距离——所有指廊都从同一座主楼出发，最远端的距离被压短，转机旅客不必穿越整座建筑再折返。

放射状当然不是新发明，但“六指廊”的规模在国内是第一次。指廊越多，主楼与指廊的交接面越复杂：行李系统要在分叉处转弯，机电管线和消防分区要重新计算。这类构型因此更常见于吞吐量足够大的枢纽机场。

## 三、“长安盛殿”：唐风屋顶怎么落到钢结构上

T5 的设计理念是十六个字：“长安盛殿、丝路新港、汉唐风韵、城市华章”。落到具体形态上，是两个可以指认的动作：屋顶的“双坡双脊、重檐三叠”，以及支撑屋面的 Y 形柱。

用直白的话说，屋面不是一个平板：两道坡、两道屋脊，再叠出三层檐口，远看像几座唐代宫殿的屋顶被放大、拉平、连成一片。它借的是传统建筑里“檐”的层次感——屋檐层层出挑，光影有了深浅，巨大的金属屋面因此不至于变成一块平淡的盖子。

Y 形柱则是结构上的应对。屋面的跨度很大，如果按常规每隔几米落一根柱子，大厅会被切得支离破碎。Y 形柱让柱子在接近屋面处分叉，像树枝一样托住上方结构：落地柱的数量减少，柱身可以做得细一些，视线更通透，荷载又通过分叉分散到更大的屋面面积上。

这套形态还呼应了西安“四方城”的城市格局：直线型的规整轮廓与城墙围出的方形秩序同构，殿式空间、坡屋顶与柱式则把“汉唐风韵”从口号变成旅客能看见的形体。设计方同时强调绿色建材与低能耗运行，希望它成为低能耗空港的一个样本。

## 四、四层分区、双层出发到达：把 8000 万人次拆开

T5 采用“四层功能分区 + 双层出发、双层到达”的模式。这句话听着抽象，实际意思是：航站楼按功能分成四层，出发和到达又各自分成两层，不同方向、不同性质的客流走不同的楼层。

为什么要这样分？年设计容量 8000 万人次的航站楼，高峰时段的人流是惊人的。如果所有出发旅客都在同一层值机、同一层安检，柜台和通道再怎么加也会堵。把出发拆成两层，等于把同一时刻的客流分成两股，各自拥有值机岛、安检通道和通往指廊的路径；到达拆成两层，行李转盘和接机区也一分为二，到达旅客不必和出发旅客对冲。

对旅客的感受是“分层不打架”：你所在的那一层，只服务一部分航班，队伍短一些，找柜台也快一些。8000 万人次的容量，靠的正是这种把客流拆散的布局，而不是单纯把楼盖大。

## 五、“一张脸走到底”与“零换乘”

在流程层面，T5 部署了“一张脸走到底”的智慧通关服务：以人脸作为身份凭证，把值机、安检、登机串起来，减少反复掏证件、反复排队的次数。这不是某一个闸机的新功能，而是把身份核验从“每个环节各做一次”改成“一次注册、全程通行”。

行李系统用的是全国领先的全封闭式悬吊行李钢平台。拆成两半看：全封闭，指行李在封闭通道里运输，不与人流交叉；悬吊钢平台，指整套设备架在悬挂于主体结构的钢平台上，而非填实的混凝土楼板上——自重更轻，下方空间的高度也被释放出来。对旅客来说，这些术语的落点只有一个：行李更少出错。

航站楼还与综合交通中心无缝衔接，组成“航空 + 轨道 + 公路”的立体交通网络，目标是“零换乘”“快通关”。对旅客来说，这意味着从轨道交通或长途巴士下车后，不必先出楼、再进楼、重新排队，而是沿同一条通道完成值机和安检。

## 六、奖项之外，一座建筑要回答的问题

Skytrax 在国际航空运输评级领域被称作航空业的“奥斯卡”，评选基于对全球 100 多个国家、500 多座机场的旅客满意度调查。按设计方的说法，T5 的“全球最佳新机场航站楼”第二名，是国际旅客对其设计理念、运行效率和人文关怀的认可。

但一座航站楼最终要回答的问题，比奖杯朴素得多：旅客能不能少走一点路，行李能不能准时出来，转机能不能不慌，老人和孩子能不能找到座位。T5 的六条指廊、双层出发到达、悬吊行李平台和零换乘通道，都是对这几个问题的技术回答；屋顶的坡与脊、柱子的分叉、中轴上的殿式空间，则是另一层回答——它告诉到达的人，你到的是西安。

这也解释了设计方为什么会用“以建筑之美讲好中国故事”来总结这个项目。对每天走过这座楼的人来说，故事讲得好不好，取决于下一次从 T5 出发时，值机、安检、走到登机口这几步顺不顺。
