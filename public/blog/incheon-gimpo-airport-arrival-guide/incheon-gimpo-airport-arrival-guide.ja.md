ソウル行きのフライトはすべて同じ場所に着陸するわけではありません。仁川（ICN）は西海岸沖の永宗島にあり、金浦（GMP）は市の西端に張り付いています。どちらもソウルへ出られますが、列、所要時間、切符のルールは2つの異なるシステムに属します。「間違える」ことは致命的ではありません。1〜2時間と多くの荷物の引きずりを損するだけです。

本ガイドでは順に説明します。まずどちらの空港か、次にどのルートか。距離と入国審査、仁川の2つのAREX列車の見分け方、金浦がなぜ約20分でソウル駅に着くのか、バスとタクシーの料金、そして到着時の書類、Q-CODE、C-3-9ビザ、金浦でビザ免除旅行者が引っかかる1つの制限です。運賃と時刻表は変わるため、搭乗前に公式情報を確認してください。

## 1. 仁川と金浦：2つの空港、2つのリズム

仁川国際空港（ICN）は市の西約50kmの永宗島にあり、韓国の国際線の大部分を担っています。ソウルへ直行便がある中国の都市の多くはここに着きます。24時間運営なので深夜便の到着も問題なく、第1・第2ターミナルは免税店、レストラン、乗り継ぎ施設が充実しています。代償はその大きさです。航空機から入国審査、そして手荷物ベルトまでの歩きが長いのです。

金浦国際空港（GMP）は中心部からわずか約17kmで、コンパクトなターミナルのため到着ロビーから地下鉄と空港鉄道まで徒歩数分です。国際線網は小さく、上海虹橋、北京、東京などの短距離路線が中心で、免税エリアも小さく店が少なく、大部分は国内線、特に済州行きです。入国審査場は小さく、通過に20〜40分かかるのが普通で、通常は仁川より速いです。

選択はフライトとホテルから始まります。運賃が同程度で弘大や中心部に泊まるなら金浦です。節約できる1時間は現実のものです。自分の都市から仁川への直行便しかない場合、深夜便の場合、空港の免税エリアに時間を使いたい場合は仁川です。ターミナルも確認してください。大韓航空とほとんどのスカイチーム便はT2を使い、中国の航空会社は主にT1です。無料シャトルが両ターミナルを約18分で結ぶので、乗り継ぎには少なくとも20分を見込んでください。

## 2. 一覧比較

| | 仁川 (ICN) | 金浦 (GMP) |
| --- | --- | --- |
| 市街からの距離 | 約50km、永宗島 | 約17km、西端 |
| ターミナル | T1とT2、無料シャトルで連絡（約18分） | 国際線と国内線の建物が別々、徒歩で移動可 |
| 入国審査 | 順調で30〜60分、繁忙期はより長い | 20〜40分、通常はより速い |
| 市内への主なアクセス | AREXエクスプレスまたは各駅停車、空港バス、タクシー | AREX各駅停車、地下鉄5号線・9号線、空港バス |
| ソウル駅まで | エクスプレス43分（T1）、51分（T2）。各駅停車58〜66分 | AREX各駅停車で約22分 |
| 参考運賃 | エクスプレス13,000ウォン、各駅停車4,750ウォン（T1）または5,350ウォン（T2） | T-moneyで約1,750ウォン |
| 向いている人 | 深夜便、直行便が多い、免税、重い荷物 | 弘大や中心部滞在、短距離路線、厳しい日程、軽い荷物 |

中ほどの2行は流し読みしがちです。入国審査と移動は別々のコストです。仁川では30〜60分の入国審査の後に少なくとも43分の鉄道が続きます。金浦では20〜40分の後にソウル駅まで22分です。子ども連れや0時近い着陸では、その30分が夜の過ごし方を決めます。

## 3. 仁川から：2つのAREX列車を間違えない

手荷物受取後、**공항철도 AREX / Airport Railroad**の表示に従ってB1階の交通センターへ降ります。AREXは似た名前の2つのサービスを隣接するホームから運行し、間違えると7〜8駅余分に停まります。

- **エクスプレス：** 仁川T1またはT2からソウル駅まで直行。T1から約43分、T2から約51分、大人13,000ウォンで座席指定です。**T-moneyは使えません。** 別途切符が必要で、多くの人が改札で初めて気づきます。ホテルがソウル駅や明洞の近くにある場合、または荷物があり到着時刻を予測したい場合に向いています。
- **各駅停車：** 仁川空港→金浦空港→デジタルメディアシティ→弘大入口→孔徳→ソウル駅、端から端まで58〜66分。T1から約4,750ウォン、T2から5,350ウォンで、T-moneyが使えるので思いついてすぐ乗れます。弘大、節約、軽い荷物に向いています。

おおよそ、エクスプレスは05:15〜22:48、各駅停車は05:18〜23:32です。旅行日についてAREXのサイトで確認してください。終電後に着陸した場合、残るのは深夜の空港バスかタクシーです。

空港バスは路線により参考6,000〜17,000ウォンで、65〜90分かかります。重い荷物は荷物室に置け、明洞や江南へ直行する路線もありますが、交通事情で時間が読みにくく、深夜便は少なくなります。日中の都心までのタクシーは約50,000〜70,000ウォンで夜間割増があり、大きな荷物のグループには価値がありますが、1人では割高です。

## 4. 金浦から：ソウル駅まで22分

金浦の利点は、駅がターミナルの真下にあり、到着ロビーから徒歩数分であることです。ここにはAREXエクスプレスはなく、各駅停車だけです。金浦空港→弘大入口→孔徳→ソウル駅、約22分、T-moneyで約1,750ウォンです。

地下鉄は選択肢を増やします。5号線（紫）は金浦空港駅から汝矣島、光化門、東大門方面へ走り乗り換えも容易です。9号線は江南、新論峴、高速バスターミナル方面へ向かい、漢江の南では明らかな選択です。弘大、汝矣島、中心部への所要時間はおよそ20〜35分で、金浦では地下鉄もAREX各駅停車もT-moneyが使え、仁川より簡単です。

金浦からの空港バスは仁川より少なく、利点もほとんどありません。地下鉄のほうが良い選択です。

## 5. 着陸前に：Q-CODE、ビザ、済州の落とし穴

両空港とも到着準備は同じです。着陸前にQ-CODE（入国前検疫情報フォーム）を入力すると検疫カウンターでの時間を節約できます。C-3-9観光ビザで旅行する場合は、帰国便の切符とホテル予約をスマートフォンに入れておいてください。税関が抜き打ちで確認します。T-moneyカードはどの空港のコンビニでも購入・チャージできます。仁川ではAREX各駅停車のみ、金浦ではバス、地下鉄、コンビニ、ほとんどのタクシーで使えます。

1点強調しておきます。**済州へのビザ免除フライトは主に金浦の国内線ターミナルに到着し、ビザ免除の入国者は国内線でソウルへ移動できません。** つまり「済州へビザなしで飛び、そこからソウルへ」という計画はチェックインかゲートで崩れます。済州から金浦は韓国の国内線で、適切なビザまたは在留資格が必要です。予約前に自分の入国資格を確認し、うまくいく前提で2区間をつなげないでください。

## 6. 泊まる場所でルートを選ぶ

- **弘大に泊まる：** 仁川からはAREX各駅停車が弘大入口へ直行、金浦からは同じ列車で約22分。
- **明洞またはソウル駅近くに泊まる：** 仁川からはAREXエクスプレスでソウル駅まで43分、金浦からは各駅停車でソウル駅に出て地下鉄に乗り換え。
- **江南に泊まる：** 仁川からは空港バスが直行、金浦からは9号線で直通。

どちらの空港も迷いにくいのですが、問題は情報の食い違いです。同じAREX回廊でもエクスプレスと各駅停車は運賃が2倍以上違い、交通系カードが使えるかどうかも異なります。また「金浦」は国際線と国内線で2つの別の建物を意味します。ターミナル、列車の種類、ホテルを1つの計画にまとめれば、最初の1時間を失わずに済みます。
