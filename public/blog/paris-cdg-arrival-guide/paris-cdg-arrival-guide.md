距离开学的日子近了。第一次去法国，除了买好机票，落地之后怎么走出机场、怎么去学校所在的城市，同样要提前想清楚——法国除巴黎之外，里昂、波尔多、马赛、斯特拉斯堡等城市也有国际航班，但从中国出发的航班，绝大多数会降落在**巴黎戴高乐机场（CDG）**。

好消息是，戴高乐机场对中文旅客相当友好：从登机、值机到洗手间都标上了中文，落地之后跟着牌子走，基本不会迷路。这份指南按**落地认路**、**航站楼与火车**、**下一程怎么走**和**机场法语速查**四部分整理，刚拿到录取通知的同学可以先收藏。

## 一、落地第一步：认路与中文指引

### 通关隧道：三块牌子决定去向

下飞机后走进的第一段路，通常是戴高乐机场著名的「通关隧道」——一条长长的自动步道，头顶的指示牌已经替你分好了流：

- **Correspondances / Transfer / 转机**：不出机场，直接去下一段航班的登机口；
- **Bagages / Baggage / 行李**：去行李转盘提取托运的行李；
- **Sortie / Exit / 出口**：提取行李、通过海关之后，从这里离开机场。

第一次来法国，最容易犯的错是盯着「出口」一路走出去，而把自己的转机或高铁行程忘在脑后。记住这三块牌子的顺序：**先看是不是要转机，再决定去取行李还是直接出关**。

### 中文指引，从登机口一路标到洗手间

戴高乐机场把中文做成了完整的「一条龙」指引：登机口写着「Embargement - Boarding - 登机」，值机区写着「Enregistrement - Check-in - 办理值机手续」，连洗手间都在法文、英文旁边加上了「洗手间」三个字。巴黎市区的指示牌也常见中文，所以第一次到法国，语言并不会成为找路的障碍。

### 小心黑车：认准正规出租车与付费搬运

机场里到处贴着醒目的警示牌，用中、英、法三种语言提醒旅客：**「非法营运出租车 = 实实在在的风险」**（FAUX TAXI = VRAIS RISQUES）。落地后请到正规出租车排队点上车，或在网约车指定接客点上客，不要接受主动搭话的「司机」。

如果行李多，可以使用机场官方的**行李搬运服务（Porteurs / Porters）**，柜台标有电话号码，属于付费服务；行李手推车同样需要付费，备好零钱或能刷的银行卡会方便很多。

## 二、航站楼、火车站与机场内部交通

### 三个航站楼，T2 里还藏着七个子楼

戴高乐机场共有 **T1、T2、T3 三座航站楼**。T2 是主航站楼，被分成 **T2A、T2B、T2C、T2D、T2E、T2F、T2G 七个子楼**，呈花瓣形对称排列；T1 是一座飞碟形的圆形建筑，位于机场西北侧；T3 规模最小，在机场北部，主要供廉航与包机使用。

![戴高乐机场整体布局图：T1 圆形主楼、T3、T2A–T2G 七个子楼，以及停车楼、CDGVAL 轻轨线路和 Roissypole 交通枢纽的相对位置](./images/5.webp)

几个航站楼之间距离不近，但布局清晰：**看清自己航班所在的是哪个子楼**，再决定怎么过去。登机牌上的航站楼编号（例如 T2E）就是你的目标。

### 机场火车站：RER B 与 TGV 都在 T2

戴高乐机场的火车站设在 T2 地下，全称 **La gare SNCF de l'aéroport Paris-Charles de Gaulle**，从航站楼乘扶梯即可直达。按机场官网的说明，这座车站连接 TGV 南线、西线、北线，以及 Ouigo、Thalys、Eurostar 等主要线路，也可以在这里乘坐 **RER B** 前往巴黎市区。

![戴高乐机场 T2 火车站的分层示意：Niveau 2 GARE（站厅层）与 Niveau 1 QUAIS（站台层，RER B 与 TGV 大线列车），上方依次是航站楼到达层与道路层](./images/6.webp)

| 线路 | 在这里可以去 |
| --- | --- |
| RER B | 巴黎市区（巴黎北站、Châtelet 等），约 25–30 分钟 |
| TGV 南线／西线／北线 | 里昂、波尔多、南特、里尔等法国各地 |
| Ouigo | 廉价高铁，通往里昂、马赛等方向 |
| Thalys／Eurostar | 布鲁塞尔、阿姆斯特丹、伦敦等邻国城市 |

**第一次来法国，建议提前买好票**：站内虽有售票机和人工窗口，但落地后取行李、找车站都会花时间，遇上出行高峰期还可能买不到当天的车票。可以在国内先下载 **SNCF Connect App**，或直接在 sncf.com 上购票（需要一张能刷欧元的银行卡）；车票通常是电子票，扫码即可乘车。也可以请已经在法国的同学帮忙购买。

### CDGVAL：24 小时运行的免费轻轨

在机场内部换航站楼、去停车场或去火车站，靠的是**免费轻轨 CDGVAL**（也叫 RoissyVal）。它的线路很简单：T1 → 停车楼 PR → Roissypole（T3 所在，步行约 5 分钟进 T3）→ 停车楼 PX → T2，在 T2 可以换乘 TGV 大线、RER B，旁边还有 Sheraton 酒店、酒店穿梭巴士与**行李寄存处**。

![CDGVAL 机场穿梭轻轨线路图：Terminal 1 与 Terminal 2 两端，中间是停车场 PR、Roissypole（Terminal 3 步行 5 分钟）与停车场 PX，并标注开放时间与夜间巴士替代方案](./images/7.webp)

**运行时间**：每天 04:00–01:00 由轻轨运行，01:00–04:00 由摆渡巴士代替，也就是全天不断档。别忘了机场内部还有公交线路 N1、N2（Navette 巴士）作为补充；航站楼之间的步行通道指示也很清楚，行李不多时直接走过去往往比等车快。

## 三、下一程：转机、去奥利机场、去外省

### 1. 在戴高乐机场里转机

如果下一段航班仍然从戴高乐机场出发，直接在机场内部换航站楼即可，方式是**免费的 CDGVAL 轻轨**（见上一节）。这里有一个关键判断：

- **行李不直挂（非联程票）**：必须先入境、提取行李，带着行李换到下一段航班所在的航站楼，重新办理值机与托运；
- **行李直挂（联程票）**：落地后跟着 **Transfers / 转机** 指示牌走，直接前往下一段航班的航站楼与登机口，不需要提取行李。

无论哪种情况，机场指示牌都有中文，跟着走不用担心找不到路。

### 2. 去奥利机场（ORY）

如果下一段航班从**巴黎奥利机场**起飞，两个机场之间并没有直达的轨道交通，需要在市区方向换乘。目前的主流走法是：

- **RER B + Orlyval**：乘 RER B 到 **Antony 站**，出站换乘 **Orlyval** 自动轻轨直达奥利机场（南、西两个航站区），全程约 60–90 分钟，行李多时这条线的换乘距离最短；
- **RER B + 地铁 14 号线**：进城后换乘 14 号线——该线已于 2024 年延伸到奥利机场，从市中心到机场约 25 分钟；
- **出租车／网约车**：门到门约 45–60 分钟，适合时间紧或行李多的旅客。

需要注意，早年常见的**法航大巴（Le Bus Direct，原 Les Cars Air France）已经停运**，网上仍能搜到的「3 路法航大巴」信息已经过时，别在机场里空等。

### 3. 坐 TGV 去外省

戴高乐机场的 T2 里就有一座 **SNCF 高铁站**，如果学校所在城市有直达车次，在这里直接上车最省事——不用先进巴黎市区再折返。买票方式见上一节，建议**提前购买并预留充足时间**，以免遇到迷路、取行李过慢或高峰期车票售罄。

如果机场直达的车票买不到，就需要**先进巴黎市区，再从对应火车站乘车**：机场巴士站（Gare routière）位于 T3 旁的 Roissypole，Roissybus 等线路可以进城；也可以乘 RER B 到市区的火车站。进城的票价与线路请以 Île-de-France Mobilités 公布的当日信息为准。

### 4. 巴黎六大火车站速查

巴黎市内有六座主要火车站，分别通往法国不同方向。如果你需要在市区换乘高铁，先确认车票上写的是哪一座：

| 火车站 | 主要方向 | 到站地铁 / RER |
| --- | --- | --- |
| Gare du Nord | 法国北部、比利时、英国（欧洲之星） | 4、5 号线，RER B、D |
| Gare de l'Est | 法国东部、德国、卢森堡 | 4、5、7 号线 |
| Gare de Lyon | 法国东南部、瑞士、意大利 | 1、14 号线，RER A、D |
| Gare d'Austerlitz | 法国西南部、西班牙、葡萄牙 | 5、10 号线，RER C |
| Gare Montparnasse | 法国西部、布列塔尼 | 4、6、12、13 号线 |
| Gare Saint-Lazare | 诺曼底方向 | 3、12、13、14 号线 |

到了火车站，可以直接向服务人员询问所去城市的详细班次，买好票后检票上车即可。行李多的时候，注意巴黎地铁的老线路（尤其 4 号线等）多为楼梯换乘，预留出搬行李的时间。
